# 放大训练的因素覆盖与剩余边界

本表是本轮实际检查范围，不是“所有因素均已解决”的声明。研究目标始终是共享执行模型在实际接收者知识条件下学会即时及长期合规任务策略。通过一项有限模拟，只能排除该模拟捕捉的错误。

| 因素 | 本轮证据 | 对规模化的含义 | 仍未覆盖 |
|---|---|---|---|
| 接收者已有知识 | 本地背景、授权已交付记录、草稿、同名异号及重复记录检查 | 仅看当前消息会漏掉可组合泄露；草稿不能污染已知状态 | 真实外部知识和隐含自然语言推断 |
| 可见信息与标签一致性 | 找到同一B观察、不同R隐藏背景的反向正确偏好 | 扩量前先解决信息不可辨识；拒绝矛盾pair只能挡住数据错误 | 合法查询协议、信念状态与规范允许的观察设计 |
| 自由文本语义 | 精确语义、伪造fact_ids、解析异常、改写UNKNOWN | 结构核验不能自动认证语义等价，UNKNOWN不能充当安全证据 | 自由生成正文的独立语义核验及校准 |
| 历史长度 | 0–256条受控无关记录，保持oracle标签 | 可检查闭包与成本的程序行为 | 真实模型长上下文、关键事实位置与远距离回忆 |
| 期限与动作成本 | 6种期限、3种成本配置，4/7演示与可行性核验 | 任务失败须区分不可达和策略失误；成本单位不可错误归一 | 多阶段非确定任务、真实工具失败和时延 |
| 候选覆盖 | 24种节点/动作预算，48分支证据分别保留unknown/witness/exact | “没搜到”不能变成“无解”；候选不足会改变监督分布 | 自由文本候选的召回率与匹配预算比较 |
| 参考策略质量 | 手写策略控制与冻结模型执行分列 | 参考策略相对偏好不等于最优值；成功见证与统计优势须分开 | 真正强弱LLM参考策略及跨模型可迁移性 |
| 抽样统计 | 稀有违规、零效应、多个比较、反复查看、效应量检出诊断 | 单对错误预算不能原样扩到整个训练集；零观测不证明安全 | 真实策略相关性、批量错误预算服务及anytime-valid实现 |
| 状态和版本身份 | 环境配置、累计成本、交付事件、终局、参考/生成器版本绑定 | 缓存和证据不能跨不同协议混用 | 分布式worker、外部环境与版本滚动升级 |
| 缓存、可变对象与并行 | 输入/输出快照及8线程32调用检查 | 修改一个见证不能污染其他样本 | 跨进程共享缓存、网络断连、服务重启 |
| 原始数据独立性 | 2,016原始→1,824唯一表面对→38模式→1基础任务 | 换名扩增不增加独立任务数；不能跨train/test泄漏基础世界 | 新任务答案、独立规则家族与严格留出 |
| CI/future/repair来源重叠 | 全部CI对也在repair；记录两个交集 | 不去重/不控配比会改变有效权重，不能叫DPR独立增益 | 真正独立repair任务和预算匹配消融 |
| 训练初始化与任务覆盖 | 随机与合成轨迹SFT代理分列；100%pair拟合仍会失败 | 偏好只约束被比较的动作；训练前效用和完整轨迹必须评估 | 真实基础LLM、任务能力门槛与分布外行为 |
| 源配比、顺序及标签噪声 | 66份主要有限策略，固定batch多重集顺序诊断 | 总准确率掩盖稀有CI错误；顺序效应存在于该代理 | 真实LLM的稳定性、多种子和独立泛化 |
| tokenizer和序列构造 | 见 `tokenization/` 独立CPU诊断及其报告 | prompt、completion、EOS、padding、截断须有显式合同 | 真实模型attention/position/kernel数值行为 |
| 梯度累积与优化器 | 见 `optimizer/` 独立有限DPO数学诊断及其报告 | 样本数、clip次序、Adam/RNG恢复和冻结参考决定是否同一实验 | 实际分布式框架、混合精度和多卡通信 |
| 真实本地执行 | 12段菜单策略：4成功、6任务失败、2未知 | 冻结模型可接入，但已有可避免失败；不是已训练方法 | 自由生成、多任务及训后效果 |
| 计算和资源 | 每实验worker设≤10s上限；CPU本地7B请求实际计时 | 条件估算显示LLM参考生成可能昂贵，须先预算 | GPU吞吐、显存、批处理、实际服务长期稳定性 |

后两组补充诊断以各自输出为准；不把其合成数值等价性提升为真实模型的通过结论。工作优先级是先补独立任务和可信规范/语义证据，再冻结数据与监督协议，最后开展GPU上的实际共享模型训练和匹配消融。
