The full shared-language-model CI goal remains unchanged. Prior oracle-input action binding improved but autonomous task completion regressed. First run a frozen downstream input intervention on reached states; this is diagnostic, not a complete repair or full oracle trajectory. Then test whether adding existing multi-hop TRAIN supervision improves learned relationship estimates and autonomous utility while retaining the corrected actor.

Both training arms start at the same sealed fallback_order/interleaved checkpoint. `one_hop` uses depth1 for all96jointbatches. `mixed_depth` uses depths1/2/3 in a fixed cycle, with11/11/10batches per role. History-pair sides are aligned by semantic labels, not file position. Length, entity count and token exposure necessarily differ with depth; this is a supervision-coverage intervention, not a matched-token or isolated graph-complexity effect.
