# 反事实路径兼容预训练的单种子开发试验

复用已有关系推断执行器、公开或私有的实际投影交付以及原始角色菜单。训练仅限统一 TRAIN 中的 DIRECT_JOIN，按源文件连通分组；开发源组与本轮训练互斥，使用已解封的研究面板。原始 proof_cce_7 共享 4B / LoRA r8，同种子 7。四轮均按源组整批，单臂 96 次更新、384 条曝光。前两轮与后两轮的边界对所有臂重新初始化同一 AdamW；学习率 5e-5。先执行一次，不据结果调参。

* A 四轮为精确有界规划的最优原生动作集合 CE。
* B 四轮为从同一起点作参考的动作偏好 DPO，beta 0.35。已有档案包含固定参考偏好与实际失败 DPR；为使三臂逐状态匹配，未归档的反事实状态由原生固定参考续行重评，单列来源和曝光。
* C 前两轮学习历史与一条指定完整路径的相容性，使用两个单 token 的 TRUE/FALSE 作二类交叉熵。每根含同一保护投影路径在两条真实历史下的反向标签，同时覆盖授权及上游规划。后两轮与 A 使用完全相同的动作目标、状态和菜单顺序。三个臂的原生决策继续使用 paper_policy.SharedLM 的动作提示和语义映射。

每次更新三臂填充到相同宽度，记录实际输入 token、填充 token、参考前向与时间。B 的参考缓存额外计费。既有基本任务能力由起点继承；三臂训练状态全部一致，完整自主执行包含此前未专门接受本轮标签的角色。训练路径最长 4 个动作；开发双跳完整路径为 5 个动作，条件路径只接受真实、正概率的签收，授权在路径中固定。按阶段投影为原子，穷举最小支持后计算剩余约束；每格与独立原生执行及实际业务提交核对。路径相容性按明确交付条件判断，真实机会分布下的最优顺序由原有精确规划器另行计算。自主评估固定原生 seed 0，并沿每个模型实际决策从初态执行到终止、违规或 10 步上限。

主开发指标为双跳未授权的严格成本反转：每个源根两条历史、两个共同菜单顺序均选择原生最优桥接动作。两动作均即时合法。成本不同，故不能支持即时进展及成本完全相同的反转主张。授权保持、完整自主 STSR、违规和条件成功成本同时报告。单跳/双跳、3/4/5 步辅助路径预测、训练拟合和参考一致性分开。按根配对；两种菜单顺序与同根轨迹不是独立样本。

事前开发筛查：C 在严格反转上须分别较 A、B 至少多通过 2 个根，同时相对两者在双跳未授权面板的自主 STSR 不下降、已知违规不上升。若原生评价出现地板、或相容性单项改善而行为未过门槛，裁决只允许“未建立自主收益”。若通过，仅进入独立重复的候选。冻结最终测试集与原 v0.8 NO_GO 保持有效。
