# 消息依赖修复、严格 CCE 与关系学习审计

**结论：执行器的信息旁路已修复；完整研究命题仍未证明，GPU 大规模训练继续 NO-GO。**

本轮保留 Proposal v0.6 的目标和严格 `CI > 合规任务成功 > 成本` 顺序。没有启动 GPU、没有训练真实 LLM，也没有把网关的成功计作模型学习成功。工作从 2026-11-15 18:18（Los Angeles）开始，所有实验子任务设有不超过 9.5 秒的限时，Ollama 每请求为 9.2 秒。

## 1. 已修复的执行路径

`dynamic_tasks_v2_evidence` 中，Meeting 的 `RESERVE` 现在实际消费 **HR → Room 的约束消息**。`solve_meeting(constraints, public)` 只接收交付的约束与公开排期资源；Room 没有私人约束源权限。HR 的私人源读取、Room 的公开排期读取均经过 ACL 并写入访问日志。私人真值只供初始化评估器及最终结果判定使用，不能充当运行期输入。

Query 的 `JOIN` 消费实际交付的 counts/cities；`company_id_map` 被明确声明为 JoinTool 有权读取的公开公司名称源，并产生读取记录。`SEND_CITIES` 消费投影结果，`SEND_JOIN_RESULT` 和最终交付消费已生成的结果消息，不再从共享 `result` 缓存恢复答案。

每条交付记录有输入引用和内容摘要；每次消费有 reader 与 receipt 记录；最终 Client 结果可回溯至必要源。缺失、错投、修改、重复或不合法输入返回 `UNKNOWN` 并回滚当前动作，不留下部分副作用。模型观察只包含授权收件记录和协议资源，内部证据摘要、未来值与隐藏评估答案不进入提示。

这些摘要是**可信模拟器中的来源与完整性记录**，不是抵御任意 Python 状态篡改的签名或真实网络认证。当前 CI 规则仍是有限、合成改造的规则，不声称完整自然语言语义保证。

## 3. CCE：解决了什么，什么不能从有限采样证明

若某参考策略有违规概率 ε>0，n 次恰好无违规的概率仍为 `(1-ε)^n`。因此，有限个零违规样本不能证明两个任意 LLM 分布具有严格相同的 CI 风险。缩小置信上界也不等于严格等价。本轮没有放宽为 ε 风险交易；无证明的原始 LLM 路径仍保留 `UNKNOWN`。

新增的是明确不同的参考策略合同：

`冻结 LLM 提议 → 严格动作解析 → 可验证执行网关 → 工具`。

- **CI-only**：所有可执行后继均验证为安全。非法提议被记录并替换；无安全后继则停止。由状态不变式证明实际执行 CI 安全，与原始字符串分布无关。任务成功率仍可能不同。
- **safe-success**：在安全动作中，仅保留有合规成功续行的动作。两条被比较的首动作必须本来就安全且可完成，不能替换首动作“制造价值”。有限递减期限与可达性不变式保证最终成功，才允许进入成本层。

证明枚举的是有限工具状态转移，不是 LLM 全输出分布。绑定包含数据、ACL、实现摘要、初始状态、首动作、参考策略身份、模式与成本单位；比较器只接受该网关注册过的实际执行记录，不能给任意 `Trial` 借用证书。

**边界很重要：safe-success 使用精确的有限可达性规划，是强评估器/网关能力，不是模型已经学会规划。** 本轮验证图只有 22–60 个状态。真实开放工具、自然语言不确定性、不可枚举长流程仍未解决；没有可靠上层合同就仍然不能下探成本层。

详见 [CCE 合同与证明条件](CCE_CONTRACT.md)、[执行网关](../../code/kci/execution_envelope.py)。

## 4. CCE 校准与真实 Qwen 续跑

校准覆盖 2 任务 × 2 历史 × 2 网关模式 × 2 成本单位，共 16 个比较。初始 n=64 与宽范围 n=256 均为 16/16 `UNKNOWN`，这些记录全部保留。随后使用**采样前由工具图证明的成本差范围**，在 n=256、每比较 δ=0.01/16 下得到 7 个成本偏好、9 个 `UNKNOWN`；CI-only 的 8 个比较全为 `UNKNOWN`。这三个版本是探索性迭代，不是独立重复实验。

20 份最终执行记录（16 个校准、4 个 Qwen 比较）已重放核对，共 **39,814 次实际执行转移**。校准另与独立均匀逐步提议的理想化分布作有理数期望检查，7 个输出方向均相符；该理想化分布不等于对 PRNG 所有种子或 Qwen 概率的精确枚举。

真实模型为本地 `qwen2.5:7b-instruct-q4_K_M`，CPU，固定摘要、提示与采样设置。首动作固定为反事实两分支；每个后续状态都调用 Qwen，包括只有一个动作的状态。每比较 n=2，共 **88 次任务请求 + 1 次预热**，无重试，最长请求 8.699 秒，模型摘要未变，结束后已卸载本轮加载的模型。

| 条件 | 受控分支续跑成功 | 全程无需替换的续跑 | 替换提议/提议数 | CCE |
|---|---:|---:|---:|---|
| Meeting，无相关历史 | 4/4 | 0/4 | 6/22 | UNKNOWN |
| Meeting，有相关历史 | 4/4 | 0/4 | 8/22 | UNKNOWN |
| Query，无相关历史 | 4/4 | 4/4 | 0/22 | 内容字节成本偏好 OPEN_INDEX |
| Query，有相关历史 | 4/4 | 2/4 | 2/22 | 内容字节成本偏好 OPEN_INDEX |

16 次续跑不是 16 个独立任务，也不是 Qwen 自主完成首动作选择。16 次替换中，4 次原提议会违反当前合成 CI 规则，12 次为安全但不能完成任务的放弃提议。**16/16 是网关保护后的成功；不能报告为原始模型 100% 成功。** 两个 Query 的字节差支持区间本就严格同号，偏好有结构性成本界支撑，不是 n=2 证明了 LLM 风险相等。

证据：[Qwen 冻结协议](qwen_envelope_v1/plan.json)、[结果](qwen_envelope_v1/summary.json)、[逐调用记录](qwen_envelope_v1/calls.json)、[执行重放审计](calibration_audits)。

## 5. 价值差异仍受成本定义影响：关键负面结果

本轮同时计量实际交付内容的规范 JSON UTF-8 字节数，排除来源信封、网络和计算开销。它比任意每动作一步更具体，但仍不是实测业务延迟/价格，序列化与协议包装也会影响它。

以下比较的是充分期限下的**最优合法续行**，不是某个冻结参考策略的均值；两者不能混用。

| 禁止敏感推断的条件 | 公共路线最少步骤 / 最少字节 | 私有路线最少步骤 / 最少字节 | 两种成本的偏好 |
|---|---:|---:|---|
| Meeting，无相关历史 | 5 / 757 | 6 / 775 | 都偏公共 |
| Meeting，有相关历史 | 7 / 1386 | 6 / 775 | 都偏私有 |
| Query，无相关历史 | 6 / 1186 | 7 / 1359 | 都偏公共 |
| Query，有相关历史 | 8 / 1186 | 7 / 1359 | **步骤偏私有，字节偏公共** |

进一步去掉成本并放宽期限后，2 任务 × 2 历史 × 2 权限，共 **8 个配置**的两条首动作都具有合法成功续行，最优任务值相等。也就是说，真实消息依赖修复后，原初始路线的严格排序仍不能独立于成本/期限设定成立。

参考策略本身也影响 CCE。例如相关历史的 Meeting：最优步数是公共 7、私有 6；但均匀提议加固定网关后的理想化期望为公共 7、私有 7.5，方向相反。这不是排序器算错，而是 **参考策略价值不等于最优规划价值**。

因此，不能通过再添加确认动作、给某一路线增加人造延迟，或仅修改权重来宣布本问题解决。必须找到独立于期待标签的业务资源依据，或源任务中真实存在的访问/效用约束。

证据：[Meeting 路线、结果来源](cost_routes_meeting.json)、[Query 路线、结果来源](cost_routes_query.json)。

## 6. 关系学习：辅助机制成功，原策略泛化门槛尚未通过

新增一个 CPU 上可训练的通用三跳消息传递分类器。输入只有显式实体绑定、三类关系边、敏感端点与可见权限；没有预计算 closure、风险、未来值或标签特征。每个权限/匹配分层独立平衡，正负例节点/边数量相同。

固定 256 个训练图；测试为新绑定、扩大到五组实体、分支中间连接三种条件，各 256 行。固定 300 步、宽度 8、3 个种子，没有据测试结果调参。门槛为每个种子、每种条件、每个权限/匹配分层都至少 95%。

| 模型 | 三个种子分别答对/768 | 完整诊断门槛 |
|---|---|---|
| 无消息传播 | 576、576、576 | 0/3 通过 |
| 两跳 | 576、576、576 | 0/3 通过 |
| 三跳 | 768、768、768 | 3/3 通过 |
| 三跳、打乱训练标签 | 384、640、384 | 0/3 通过 |

这支持一个有限结论：给定结构化实体绑定，训练网络可以学习当前三关系与权限组合，浅层信息不可达的对照失败。节点重编号不变性已核对。

**不能扩大解释：** 名称不变性由图表示中的精确实体解析提供，不是模型学会字符串匹配；很多图彼此同构，768 行不是 768 个独立任务。它不是共享执行 LLM、不是端到端行动策略，不是独立来源任务留出。分支图超出当前运行期规则的功能键假设，只能算辅助结构压力测试。旧文本有限模型严格等长新符号测试的失败仍保留，不能被此图分类器成绩覆盖。

证据：[事前诊断方案](RELATION_PROBE_PLAN.md)、[固定图数据](graph_data/DATA_CARD.json)、[全部权重与预测](graph_models)。

## 8. GPU 决策与剩余卡点

**可以继续：** CPU 上的执行器、结构化关系表示、任务合同与数据改进；有限、显式规范环境中的受控参考 CCE。

**暂不投入：** 大批量 GPU 偏好训练，或声称已经证明“模型学到真实信息流任务规律”。关键卡点是：

1. **业务价值合同尚不足。** 必须先确定独立来源的传输/计算成本、截止期或不可替代的信息需求。当前 Query 换成本单位即反向；零成本宽期限下所有初始路线同值。
2. **完整策略学习证据缺失。** 图分类器只是辅助模块。还需在同一执行策略上做符号置换、关系重绑定、成本/流程长度解耦、跨实例留出，并区分表示提供的能力与训练获得的能力。
3. **任务与规范覆盖不足。** 只有两个源实例及共用三关系语法；规范未独立人工验证。扩展到新规则/多值关系或自然语言，现有证明不自动成立。
4. **通用 CCE 的数学/计算边界。** 任意原始 LLM 的严格风险等价不能由有限零样本证明；受控合同提供一条可执行路径，但精确可达性和可靠 CI 判定在开放环境仍可能不可得。

本轮已经能证明“必要交付参与了实际计算”，并给出“结构化关系模块可学习”的初步证据；尚不能合并成用户要求的完整研究证明。继续保持 GPU NO-GO，不以网关、图编码或合成流程替代该验收标准。
