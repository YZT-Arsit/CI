# 完整目标与本轮边界

研究目标继续以 [Proposal v0.6](../../docs/KCI_Align_Research_Proposal.md) 为准：共享执行语言模型基于可信交付历史、接收者知识、权限与任务依赖，自主选择合规且有效的行动。本轮没有将目标改成单独的图分类或解释生成。

| 要求 | 本轮检查 | 仍需完成 |
|---|---|---|
| 关系知识进入行动 | 在已有条件Worker恢复基础上训练局部关系与见证，并重测行动保留。 | 把模型自产的关系状态接回完整CI行动，保留错误状态及实际后果，不由oracle代答。 |
| 学习关系而非固定符号或长度 | 新生成世界、两词池、两呈现、等长度变化配对、方向/前沿/边重接、随机图。 | 这些仍是开发中的合成语义；新名称和种子不等于独立结构与业务泛化。还需可信交付、类型组合、权限和任务依赖的完整检查。 |
| 安全和效用共同成立 | 正确外部判断下，重复使用的24个Worker状态各测六种排列。 | 这不是自主闭环，也不覆盖Planner、Source或全局查询保留；自主任务完成与违规必须共同过关。 |
| 自然业务规范有效且跨任务适用 | 本轮未新增该类模型实验。 | 既有[真实条款探针](../20261117_grounded_norm_probe/REPORT.md)中明确条件48/48一致，UNKNOWN36/36错误；还需独立审核、信息不足处理和新工作流验证。 |
| 32步真实Agent协作 | 本轮没有新增自主回合、消息或工具执行。 | 既有[原生探针](../20261117_native_agent_probe/REPORT.md)虽记录32次模型决策、31条送达消息，但成功工具调用和环境状态改变均为0。必须有真实有效执行，不能以32跳或空对话代替。 |
| 可扩大GPU实验 | 本轮仅是CPU局部监督对照，额外见证增加了计算。 | 局部门槛即便通过也不足以完成整个目标；自主机制、外部有效性和匹配对照尚需成立。大批量GPU仍为NO_GO。 |

本轮的有效见证是独立请求上的语义证书，不是已经证明的内部决策原因。任何局部改善都必须与对应失败和未完成项一起报告；完整目标保持未完成。
