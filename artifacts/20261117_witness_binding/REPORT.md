# 辅助见证监督：关系学习与行动保留的配对检验

**辅助见证方案尚未在三个日程上通过预设联合必要门槛，完整研究目标仍未完成。大批量GPU仍为NO_GO。** 本轮实际训练了六个CPU LoRA检查点，并在相同题目上测试三个原有检查点；比较同时保留行动重放的二值监督与额外见证监督。结果同时报告关系、有效见证和条件行动，任何局部增益都不能代替模型自产判断驱动的安全执行。

最重要的发现是：继续用扩展数据训练二值判断，三个日程的变化配对由59/51/57提高至103/106/106（各144对）；额外见证监督则只有80/85/80，比匹配的bit臂分别少23/21/26对。这个配置不支持“让模型写见证就能改善关系判断”的修复假设。所有proof臂都保住了条件Worker行为，但bit29仍出现1次不安全动作，不能宣布安全—效用联合问题已解决。二值续训的进展同时包含新增数据、更新和已有初始化的作用，未隔离为数据覆盖的独立因果效应。

通俗方案见 [SOLUTION.md](SOLUTION.md)，完整研究范围见 [OBJECTIVE_AUDIT.md](OBJECTIVE_AUDIT.md)。数据、代码、检查点和负面结果均保留。

## 修复与配对设计

原局部训练的数据结构较窄，名称／顺序干预也已显示预测不稳。本轮扩展到8/12/16节点生成域、1–4个初始已知节点、变化目标、方向环长度4–7，以及多个合法来源。未出现于提示中的孤立节点不会增加真实输入规模，实际打印节点分布见 `DATA_AUDIT.json`。这不是旧数据对新数据的单因素实验，不能认定旧覆盖是失败的唯一原因。

每个日程有768条新生成训练世界记录，共2,304条；两种训练臂重复使用对应的同一批记录，不能算成4,608个独立世界。每批四题，严格两正两负。包含保持度数的边重接、图不变而已知前沿改变、保持无向图与度数的方向反转，以及目标已知、无初始知识、仅两跳可达、多合法来源四种边界控制。

日程17/29/41分别从对应已冻结的行动重放适配器开始。每对bit/proof初始化参数完全相同；三个日程的初始适配器不同，但共享基础模型来源。各192次更新，fresh AdamW、学习率0.0002、CPU FP32、四线程，只取最终检查点。bit学习二值判断和原TRAIN Worker行动；proof额外在同四个世界上学习有效见证集合的概率质量。格式／EOS使用其中一个合法教师序列，因此不宣称整个目标严格对并列选择无偏。

两个训练臂的二值与行动批次完全相同。辅助见证增加token与计算，本轮不是等计算量的方法优越性比较。测试中的二值提示相同；证明问题另行生成，既不把真值见证喂给模型，也不把生成的见证替换成正确答案。不存在运行时图规则兜底。

实际结果表明问题并不只出在新题：辅助见证模型对各自24个已见正例也只生成14/13/10个合法见证，二值配对13/8/11仍低于bit的15/14/14（各18对）。这些实例在当前续训只呈现一次，因此不能据此宣称“充分训练仍不可能学会”，但也不能把当前失败仅归为新名称或分布外泛化。

下一步应保留二值续训作为参照，先拆查目标实体复制、边方向读取和“已知来源与目标入边匹配”三个技能，再决定监督或优化如何调整；当前证据不支持继续默认加大这项见证损失。修复后仍须用新预先固定的数据检查关系及条件行动，再接模型自产状态的自主闭环。长流程会暴露局部错误及其传播，本轮不能用单步平均分估算或宣称32步Agent成功。以上是待执行路线，不是本轮已完成结果。
