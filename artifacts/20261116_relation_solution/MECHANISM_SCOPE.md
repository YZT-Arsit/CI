# What the present evidence does and does not prove

For the adapted receipt contract, write `Reach(p, H)` for a directed path from
the selected ticket through that provider's declared links to a history key
actually delivered to recipient R. Let `P` mean explicit permission and `B`
mean the original commitment requires the complete binding fields.

At the initial Planner state, each COMMIT is immediately compliant. Its
attainable compliant task value is

`V(Commit(p)) = 1` exactly when `P or not B or not Reach(p, H)`.

Reason: when B is true, successful completion must publish this provider's
binding; a delivered history at its reachable endpoint then reveals the protected
relation. WAIT and rerouting do not erase R's knowledge or discharge the original
commitment. When B is false, the native result can be sent without the binding.
When P is true, the same derived relation is permitted. There is no trajectory
length penalty, deadline or arbitrary privacy weight in this exact target.

This is a conditional statement about the explicitly defined synthetic norm and
task contract. It is not a theorem that these added obligations are natural or
that a real person would endorse every norm. Eight additional source task
computations do not supply that missing independent norm validation.
The native-output control removes the added receipt fields, but its candidate
disclosure protocol and initial knowledge/norm remain adapted. It is not a full
native benchmark agent replay, and it does not independently validate the
necessity of every available/omitted disclosure action in an unrestricted task.

The training dataset labels were computed by executing all available actions and
their continuations. A separate directed-BFS implementation reproduces all saved
immediate-safety and feasible-completion labels. The test interventions preserve
symbol inventories, candidate order and chain lengths while swapping the actual
history endpoint. Reverse/broken edges preserve most surface statistics while
changing reachability. Authorization, optional binding and undelivered-history
controls test whether the policy respects conditions on the rule.

Symbol transfer here means entity IDs/names and their relational assignments.
The meanings of I/L/H relation types and the norm grammar remain fixed. These
tests do not establish transfer to unseen norm predicates or free-text norm parsing.

The structural model adds a known hypothesis class: shared max-min propagation,
learned relation gates and a learned endpoint matcher. Its local primitive
supervision teaches the norm grammar and same/different matching. Thus successful
depth extrapolation demonstrates use of supplied compositional structure; it
does not show that a language model discovered the closure algorithm unaided.
The 64D repair changes only continuous entity representation and capacity, while
retaining exactly the same weights. It removes observed near-match failures on
a new 192-world confirmatory set. These worlds are reused across three seeds,
so 576 trajectories are not 576 independent tasks.

The reference action selector scores `4 * sigmoid(CI) + sigmoid(value)`.
This fixed scalarization is an implementation choice, not a formal safety
guarantee or a term in the executed value-label definition. The factor 4 was
not searched against these test results; imperfect learned probabilities can
still produce unsafe actions. The observed gate remains empirical and bounded.

The actual language-model comparison is separate. All arms start from the same
pinned SmolLM2-135M-Instruct base; the core comparison is paired SFT with or
without generated proof targets. A later component-balanced arm was frozen after
unique-choice DEV failures and before any primary language test output was read.
It balances action/safety/task/path/format losses, rather than allowing many
format tokens to dilute decision supervision. All proof text at evaluation is
generated by the model. An independently checked valid path and correct safety/
task labels are required to call that generated proof faithful.

None of these SFT experiments measures the proposed KCI DPO method's distinct
benefit. A GPU run must retain these distinctions: learnability, method benefit,
external CI validity and deployment reliability are separate claims.
