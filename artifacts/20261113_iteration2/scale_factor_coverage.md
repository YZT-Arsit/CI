# 两轮规模因素覆盖与尚未通过的门槛

研究目标保持不变。本表区分有限 CPU 检查、真实冻结模型执行和尚未完成的验证；不声称已经穷尽大规模训练的所有因素。上一轮的完整记录见 [原因素表](../20261112_cpu_pilot/scale_factor_coverage.md)。

| 因素 | 第二轮新增证据 | 对放大实验的约束 |
|---|---|---|
| 来源文本与结构一致性 | canonical renderer；34 个矛盾注入拒绝；112 配置重生成 | Fact 值、文本或原始来源变更后必须重新认证，不能沿用旧标签 |
| 接收者知识和推断前提 | 4 类精确规则；键、scope、完整集合、精确差分边界 | 仅覆盖声明的合成知识；自然语言和开放世界仍未验证 |
| 观察可辨识性 | 3152 精确 Prompt 类中隔离 96 条非一致严格偏好 | 更多隐藏状态可能产生新歧义；字符串相同检查不穷尽语义等价 |
| 任务、答案和数据独立性 | yes/no、3 类运算、4 规则骨架；4 折结构留出 | 仍只有 1 个共同 workflow，不能按配置数报告独立任务泛化 |
| 来源规范 | 固定官方 PiSAs/MultiAgentPrivacy 字节和原生暴露链 | 静态原子标签不能直接认证派生动态 CI；来源锚点未进入训练 |
| 外部任务效用 | Meeting/Jira 共 4000 个方案独立约束枚举，分别有 1 个完整约束解 | 局部 canonical 合同可执行；动态流程、自由文本抽取和可见证据仍未认证 |
| 长历史与位置 | 80 等长相关/无关组、140 唯一偏好；前/中/后位置 | 合成初始账本不是 256 步真实轨迹；词汇捷径和真实模型长上下文待验 |
| 截断和预算 | 完整 pair 最长 21061 tokens；4k 只保留 40% matched 数据 | 不得默默截断、删除长样本后仍声称完成长历史目标 |
| EOS、mask、padding、position | 可复用适配器和真实 tokenizer；新旧版本完整编码 | 只通过预处理合同，未接真实 Trainer/模型前后向 |
| 不可达任务 | 前缀诊断每 arm 448 回合中 56 不可达，392 可行 | 不可达必须单列，不能与模型可避免失败混在一起 |
| 策略访问路径 | 初始执行 A 全部 SKIP；合法 context 前缀暴露 4 个 arm 的违规 | on-policy 零违规不能代替其他合法历史下的条件安全 |
| 即时安全与任务效用 | CI arm 前缀违规为 0，但 392 可行回合中 310 失败 | 安全、任务成功及联合指标分别报告，不以单一 pair accuracy 替代 |
| 来源重叠与配比 | 1178 repair pair 全与 CI/future 重叠；固定来源重采样 | 重新加权不是独立新增监督，不能据此声称 DPR 独立收益 |
| 冻结参考、分组与梯度 | 40 有限模型；同 fold/seed reference 一致；训练无 heldout；双梯度核查 | 只验证有限词特征代理，不外推真实共享 LLM 梯度或方法收益 |
| 抽样置信预算 | 预声明比较和有限 look、先计账后观测、失败不退款 | 可信单账本，不是 anytime、分布式、防篡改服务；权重身份仍由调用者负责 |
| 缓存、版本和重新认证 | 最终依赖 SHA、4860 raw / 3552 状态 / 1792 DPR fresh replay | 并行 worker 必须绑定实际依赖；不得把不相关源码变更当证据漂移 |
| 真实冻结模型与 UNKNOWN | Qwen 16 回合：2 成功、8 违规、2 失败、4 UNKNOWN | 格式错误和超时不转成安全标签；10 离线修复不代表模型已学习 |
| 优化器、累积和数值 | 沿用上一轮 CPU 数学/恢复诊断，无新增真实框架实验 | BF16/FP16 kernel、DDP、scaler/scheduler、跨进程恢复都需 GPU 实测 |
| 实际算力与吞吐 | 每个实验 worker/request 上限 ≤10 秒，无 GPU 训练 | token/padding 的算术负载不等同显存、速度或 OOM 的实测结果 |
| 长短批次、排序和两 rank | 72 组完整 pair 模拟；排序减少 padding，但可能增加来源聚集或 rank 槽位偏斜 | 不能假定排序总有利；不等量尾部需真实 DDP 协议验证，不丢数据掩盖问题 |

上述通过项允许继续小规模数据与实现验证。真实任务规范、独立可执行 workflow、真实 LLM 训练和长上下文行为仍是大批量实验前的门槛。后续追加的小探索见总报告及独立目录，不改变这些边界。
