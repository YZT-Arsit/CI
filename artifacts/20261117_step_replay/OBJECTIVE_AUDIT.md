# 完整目标核对：局部重放不能替代研究目标

本轮重新读取了[Proposal v0.6](../../docs/KCI_Align_Research_Proposal.md)、当前 `code/kci/relation_language.py`、已有原生Agent探针和真实条款探针报告。完整目标不是提高一个图分类分数，而是共享执行语言模型基于可信交付历史和任务依赖，选择合规且有效的当前行动，并最终验证真实协作和自然规范使用。

| 完整要求 | 当前证据与本轮作用 | 仍需证明 |
|---|---|---|
| 动态接收者知识进入执行模型行动 | 原实现区分实际交付事实与候选计划；已有输入干预及条件动作诊断。本轮只检验局部关系训练时能否保留条件行动能力。 | 模型使用自己生成的知识判断完成自主执行，出现错误时不由真值或规则替换。 |
| 关系规律，不靠名称、顺序或流程长度 | 等长度变化配对、方向控制及新种子题目已有记录。本轮再将名称与排列做独立2×2干预。 | 在新结构/更长依赖、可信与未交付信息区分下仍有效；选定TRAIN提示的局部成功不足以证明这一点。 |
| 安全与效用同时成立 | 前一轮局部关系提高，但正确输入下行动退化；本轮试验原TRAIN动作重放。 | 自主任务完成与隐私约束同时通过，不能以全部拒绝换取安全，也不能以关系平均分抵消不安全动作。 |
| 学习的是原始CI问题 | 原语法是 `I` 后接零或多条 `L` 再接 `H` 的受限关联，并带许可和任务充分性条件。一步有向扩展只覆盖其中的一个必要操作。 | 将模型自产局部状态接回类型化知识推断、权限判断和任务依赖；显式迭代结构要披露，不能宣称模型自行发现了算法。 |
| 32步真实Agent协作 | 已有[原生探针](../20261117_native_agent_probe/REPORT.md)记录32次模型决策、31条送达消息，但成功工具调用0、状态改变0，必需转人工动作缺失。 | 在原生环境实际完成有因果依赖的协作与工具执行；不能用32跳推理、32次空对话或初始化状态通过代替。 |
| 自然业务规范及跨任务有效性 | 已有[条款探针](../20261117_grounded_norm_probe/REPORT.md)对明确条件48/48一致，但UNKNOWN36/36错误；28个案例仍为DEV-only，无人类独立核验。 | 处理信息缺失、保留UNKNOWN，并在独立审核的新情境及实际工作流验证；合成规则一致性不能替代业务有效性。 |
| 方法贡献与GPU放行 | 当前是小型CPU监督/诊断，尚无完整KCI方法收益。新增重放还增加了训练token与计算。 | 在完整机制与自主效果成立后，开展匹配对照和扩大实验；不能把可运行、局部改善或外部大模型参考当作新方法已获支持。 |

因此，重放实验即使通过其局部门槛，也不能据此把完整目标标为完成。当前无需用户新增批准即可继续已有授权范围内的CPU验证；大批量GPU仍不放行。研究负结果和未完成项保留，目标不缩减为“让单步题及oracle动作通过”。
