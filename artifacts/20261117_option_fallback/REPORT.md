# 无合规完成路径时，行动仍依赖选项位置

冻结较低学习率续训模型后，只改变选项排列并同步对应的判断字母，出现明确的位置依赖。所有事实、实体、计划、任务要求和正确完成判断保持不变。

| 状态组 | Full 位置 | 最优动作 /36 | 违规 Full /36 |
|---|---|---:|---:|
| 无合规完成路径 | A | 36 | 0 |
| 无合规完成路径 | B | 18 | 18 |
| 无合规完成路径 | C | 0 | 36 |
| 有合规完成路径 | A | 36 | 0 |
| 有合规完成路径 | B | 36 | 0 |
| 有合规完成路径 | C | 36 | 0 |

无解组的 18 个训练呈现，没有任何一个在六种排列下都选对；可完成组的 18 个呈现全部通过六种排列。无解组输出 B 共 36 次、C 共 72 次，因此不能概括成无条件恒定回答 C；但选项位置确实改变了是否选择危险 Full。正例组中 Full 可能合法，表中违规数使用独立即时合规标签，不能将选择 Full 本身当作违规。

36 个与原 TRAIN 拟合输入完全相同的提示，原始输出全部复现，没有批次路径差异。全部 216 个响应格式有效。因此在这个冻结模型、这些输入和正确判断条件下，排列干预支持该行动分支存在位置依赖；它没有证明模型所有分支都只记符号，也没有验证模型能自行生成正确判断。

案例为原 TRAIN 的全部 18 个 Worker 无解呈现，加上按 case_id 哈希选择的 18 个可完成呈现；每个遍历六种排列。保留多最优动作，选择不同的合法最优动作也算正确，不要求在存在并列最优时选同一个动作。重复状态、视图和训练样本不是独立任务。这是看过续训结果后登记的故障诊断，不是新 DEV 或独立泛化验证。

观察到的错误是：所有完成判断都为 0 时，模型仍可能按呈现顺序选择违规动作。后续应专门检验该分支是否能使用即时合规约束，并用完整排列检查修复是否消除了位置依赖，同时保留可完成任务的效用。此前有限标签兼容性检查没有发现完成判断摘要的必然冲突，因此本结果不能被写成“增加某个新字段在理论上必不可少”。

模型没有更新。54 个生成批次累计 41.514 秒，最长 0.979 秒；不含加载、哈希和审计。216 个提示、候选标签、响应、初始顺序复测和检查点均通过核验。所有规则输入均为显式 oracle 诊断，未计入自由策略收益。完整研究目标未完成，GPU 大批量仍为 NO_GO。
