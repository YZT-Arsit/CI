# 答案位等权修复未改善学习：原名退步，换名持平

本轮完成了答案位损失的匹配修复实验。**损失对称性回归已修复，但模型学习没有改善：原名关系配对从 39/48 降至 34/48，换名仍为 20/48。实际假阳性反而增加。该版本不能作为有效关系学习方案或扩大 GPU 训练的依据。** 研究目标保持不变，完整关系泛化与安全—效用学习仍未解决。

## 修复内容与控制

源代码审计发现，在当前配对训练中，全批正负类别各占一半的权重，会使同一个翻转动作的正／负样本权重成为 Planner 1:1、Source 3:1、Worker 5:1。固定负标签动作参与负类预算，带来了候选动作数量相关的训练偏好。

解析结果仅针对假设的、忽略关系的固定条件 0/1 倾向，且二值总概率质量固定。真实模型使用全词表 softmax，并同时优化格式与行动损失；不能把解析最优点直接视为模型实际概率或错误原因。详细推导和限定见[权重诊断](../20261117_small_fit/BIT_WEIGHT_DIAGNOSTIC.json)。

修复只将答案位改为 `qce[:, -2].mean()`，保留格式项、行动项及其系数，仅移除不再使用的标签计数代码。验证器逐字检查这项指定变换。回归测试直接读取实际损失表达式：原代码在增加固定负选项后出现 -1/6、-1/5 的条件对数几率梯度及标签反转不对称；修改后两个测试通过。这只证明损失性质修复，不证明模型收益。

训练从与参考完全相同的原检查点重新开始，不从参考最终权重继续。18 组关系、36 个不同观察、14 个基础组、八轮共 144 次更新，以及呈现、顺序、优化器、学习率和裁剪保持匹配。每批 token 数与 teacher 输入均核对一致。损失大小与优化轨迹可以因重加权而改变，这是该干预的后果，不能再单独归因于某个梯度机制。

方案由源代码分析提出，在参考实验完成前作本地代码／协议哈希登记；最终计划绑定完成并审计过的参考输出。这不是外部认证的预注册。参考的 480 条响应直接复用、重新评分，不算新增调用。

两组所有查询和行动均无非法输出，oracle 行动违规均为零；84 组原名／换名 token 数控制均通过。原名拟合门槛 48/48、换名门槛 48/48 均未通过。固定标签的 144 条查询合计两个词表；oracle 使用环境真值，仅覆盖 24 个 Worker 状态，不是自主安全—效用结果。

修复组原名的主要退步包括 Worker 二跳从 4/4 降到 1/4、Source 一跳从 4/4 降到 3/4、Planner 三跳从 2/8 降到 1/8。换名下 Source 三跳由 0/4 增至 1/4，Worker 一跳由 4/4 降至 3/4，因此总数持平。没有证据支持稳定的多跳关系泛化。

## 错误方向也没有按简单预期改善

补充误差统计覆盖所有查询，运行中登记且不修改主门槛，没有根据结果挑选案例。每个词表 168 条查询中，正标签 48、负标签 120。

| 答案位等权，原名 | 14 | 0 |
| 原类别平衡，换名 | 19 | 9 |

去掉解析上的正类偏置并未减少实测假阳性。这否定了“修正这个权重就能解决当前错误”的简单解释。它不否定已经验证的损失代数，也不能证明相同改动在所有模型或训练预算下无效。完整计数见 [ERROR_DIRECTION_RESULTS.json](ERROR_DIRECTION_RESULTS.json)。

此前的[小集拟合对照](../20261117_small_fit/REPORT.md)还表明，只查询监督为原名 37/48、换名 21/48，原联合监督为 39/48、20/48；也没有建立“行动损失是主要阻碍”的结论。两项诊断必须结合其有限范围理解，不能把一个合理的机制猜测升级成有效方法。

## 交付、成本与研究状态

本次等权实验新增一个检查点、144 次 CPU 更新，训练累计 571.26 秒、最长单次 5.82 秒；新增 480 条响应，生成累计 86.11 秒、最长单批 0.945 秒。与本轮小集对照合计新增三个训练检查点、432 次更新和 1776 条生成响应。另复用 144 条初始 oracle 及 480 条联合参考证据，均不重复算作新调用。时间不含加载、构建与审计，完整账目见 `DELIVERY_COST.json`。

主审计重新评分参考并要求与父实验结果完全一致，检查计划、来源、初始权重、更新、token 曝光、teacher 输入和评测前后参数身份，零错误。补充误差审计也为零错误。原始响应、失败回归、最初测试工具错误、检查点及所有负面结果均保留。[恢复与复核说明](REPRODUCE.md)提供完整命令。

本轮没有完整自主 rollout，没有独立世界测试，没有新增自然业务规范迁移或 32 步 Agent 协作证据。**GPU 大批量仍为 NO_GO。** 当前更直接的下一项检查，是在保持关系和标签不变的重复训练中增加训练词表内的重命名覆盖，再检验独立词表和结构，而不是继续把权重变化当作关系泛化已经解决。该后续实验尚未运行，也不保证有效。
