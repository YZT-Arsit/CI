# Original task rehearsal versus additional local rehearsal

Hypothesis: retaining the native task-query channel may improve autonomous safe utility after local relation training. Prior work proves that supplied judgments affect actions, but does not prove the judgments are reliable or relationally grounded. Absence of global rehearsal is a code fact, not a proven unique cause. This experiment does not change CI definitions, rewards, actors or the runtime interface.

Each update has four common local binary examples, four extra binary examples, four identical original TRAIN Worker actor-replay examples.
