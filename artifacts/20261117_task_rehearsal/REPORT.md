# 原任务判断重放：CPU配对修复报告

本轮检验“补回原任务判断监督，能否让局部关系能力支持自主安全行动”。研究目标、CI定义、任务奖励和行动接口均保持不变。

**预设的三日程共同进展判据：未通过。完整关系机制、自然规范迁移与32步有效协作仍未完成；大批量GPU保持NO_GO。**

本轮有明确的局部进展：三个起点的任务严格成功数为10/18/15，继续练局部题为10/16/8，补回原任务判断监督后为22/20/21（各28个可完成呈现）。global组三个模型均保住起点的常规关系变化对计数和条件Worker行动能力。单独提高局部分类表现，不能替代训练原任务的判断通道。

安全性仍有缺口：起点违规数为1/2/3，局部对照为4/0/0，global为0/1/4（各32个呈现）。只有日程17通过全部进展条件；29相对零违规的局部对照增加1例，41比起点多1例且比局部对照多4例。效用提高不能抵消这些违规。以上是该小型、已开发分布的观察结果，不能把原任务监督缺失认定为唯一原因，也不能据此证明局部算子迁移。

通俗说明见[SOLUTION.md](SOLUTION.md)，冻结方案见[PLAN.md](PLAN.md)，原始记录复核见[REPRODUCE.md](REPRODUCE.md)。

## 数据与成本

- 原任务训练支持为18组配对、48种状态—候选行动目标：三角色×深度1/2/3×两任务。每个日程54步，每个组合出现三次。Source/Worker的同一变化候选以两种呈现重复，未训练所有不变候选。
- 新增全局监督均为未授权、必须完整结果的条件，只含Commit/Deliver/Full判断（每个日程各72次）；没有新增Minimal/Stop、授权或允许简化条件的全局查询监督。评估保留这些控制条件，不能把这个小课程称为完整安全—效用数据集。
- 局部训练复用先前每个日程的前216个目标背景世界，三个日程共648个世界ID；使用新别名/顺序，但没有创造新任务语义。
- 六个模型实际监督回答共3,888个：公共局部1,296、额外局部648、全局判断648、行动1,296。这些是重复呈现数，不是独立案例数。
- 六种Worker选项排列在每个模型各出现36次。所有二值训练分支每批2正2负。
- 新训练检查点6个、更新324次；固定面板新响应5,472条，复用2,736条；自主回合288个，新响应2,640条（行动804、查询1,836）。合计新响应8,112条。
- CPU FP32/四线程，训练计时1129.79秒，最长单次更新4.27秒；新固定面板生成845.48秒，自主生成504.70秒；最长生成批次1.25秒。这些是实际训练/生成计时，不含加载、审计和报告。

每个模型的实际token总数见[LOCAL_RESULTS.json](LOCAL_RESULTS.json)。完整分层、不可完成任务行为和审计计数分别见[LOCAL_RESULTS.json](LOCAL_RESULTS.json)、[POLICY_RESULTS.json](POLICY_RESULTS.json)及[study/AUDIT.json](study/AUDIT.json)。

## 尚未得到的证明

即使global提高某些回合成功，也不能证明新增能力来自可组合的关系规律，更不能证明内部推理忠实。本轮缺少完全不做局部训练的全局任务对照，因此不能把global收益直接归因于局部算子的复用。这里只检验已开发任务接口中的训练分布干预。原始I/L/H类型符号仍固定；评估的1跳与3跳均在训练中出现，不是深度外推。新名称、换历史与新种子不等于未见业务规范。

本轮没有外部工具执行或32步有效协作，没有新增自然条款模型实验。既有条款探针的UNKNOWN失效问题仍在。应先让关系与行动的必要检查共同成立，再补独立组合、可信交付/权限/任务干预以及外部来源验证。当前证据不支持扩大GPU投入，也不支持宣称KCI方法收益已确立。
