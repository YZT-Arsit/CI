# External evaluation source

PrivacyLens by Yijia Shao, Tianshi Li, Weiyan Shi, Yanchen Liu, and Diyi Yang (2024), Stanford SALT lab. [Paper](https://arxiv.org/abs/2409.00138), [official repository](https://github.com/SALT-NLP/PrivacyLens), [dataset card](https://huggingface.co/datasets/SALT-NLP/PrivacyLens).

The dataset is [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); the framework code is MIT. These are distinct licenses, confirmed in the paper's distribution datasheet and the dataset card. The original repository license is retained under `source/LICENSE`. Source files are copied unchanged at revision `9c2ee07b080dc54ed4924af11d9751e81753c94d`; hashes are recorded in `SOURCE_MANIFEST.json`.

This project reserves these493external examples for evaluation only, respecting the authors' recommendation against direct training use. Local inventories and protocol notes are our additions. No source labels are changed, no trajectories regenerated, and no claim is made that these simulated trajectories constitute executed business workflows or32-step agent collaboration.
