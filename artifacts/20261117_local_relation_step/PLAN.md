# Frozen one-step relation interface diagnostic

The main research objective remains a shared language-model CI policy using trusted recipient knowledge and task dependencies. Recent loss, sampling and name-coverage changes have not jointly repaired safety and utility. Re-examine the reasoning interface before another global loss tweak. Existing trace_17 used whole PATH/SAFE/TASK supervision; it did not verify individual generated expansion steps.

Probe both final name-coverage checkpoints without updates. Test a one-round directed expansion: retain initial known nodes and add destinations of edges whose source was initially known. Do not reuse newly reached nodes within the same round. The target asks whether a named node is known after this single round. This is a new local interface and a diagnostic of frozen behavior, not direct evidence of absent neural capacity or the causal source of prior policy errors.

Self-built data:64 TRAIN pairs reserved for demonstrations or a separately registered later training stage;32 DEV seed-defined pair groups across two families and0/2/6/12 distractor-edge counts. Rewire pairs change two edges while preserving named-node indegree/outdegree, frontier, target and edge count. Reverse-cycle pairs reverse a four-node directed cycle, preserving the same undirected edges and all degrees while changing the correct one-round answer. Both receive shared distractor edges. Four presentations use two independent entity-name pools (familiar train pool and third experimental pool) and two order/name seeds.16 additional seed-defined controls cover already-known targets, empty frontiers, two-hop-only paths and direct paths. These repeat four structural templates; each noise-zero family repeats its core graph four times under different presentations. Counts are correlated, not32/16independent semantic tasks or held-out structural families. Matrix labels are checked against an independent one-round set operation; unit tests exhaust512 directed three-node graphs times8 frontier subsets. Those tests validate the oracle, not model reasoning.

Each model answers320 zero-shot and320 four-example prompts,1280 new responses total. Four examples are fixed, balanced demonstrations from the first two TRAIN pairs, with TRAIN names only. The examples condition changes both instruction exposure and prompt length; it is not a length-matched causal intervention. No example is selected from model failures. Different prompt modes are generated separately in batches4. Greedy decoding, max_new_tokens16, max_time8, validity below9.5seconds; no hard generation watchdog. Record actual prompt and padded lengths. No training or autonomous actor execution in this frozen probe.

For each mode separately, the necessary local gate is >=95% changing-pair accuracy in every family x noise x vocabulary cell (8 pairs per cell, hence all8 must pass), all64 controls correct, zero invalid and matched pair token lengths. Four-view group robustness is also reported. Failing this new-format test does not establish incapacity; a later supervised local-step pilot would need separate registration and newly generated confirmation cases. Passing does not establish multistep closure, full-policy success, natural norm validity or32step Agent collaboration. The full goal remains incomplete and GPU NO_GO.

Design reference: [ProofWriter](https://aclanthology.org/2021.findings-acl.317.pdf), sections3.6 and6.1, distinguishes generating an entire proof from repeatedly predicting a one-step implication and adding it to the context. It also discusses accumulation of errors and the computational cost of exhaustive expansion. We borrow this distinction, not its dataset or claimed performance, and do not claim faithful reproduction or novelty. Primary source located through the requested Exa connector. The architectural question is whether a verified learned local step can support a later self-generated reasoning/action loop; a hand-coded closure will not be substituted for the execution model.
