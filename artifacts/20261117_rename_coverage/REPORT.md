# 名称覆盖修复：一跳自主任务改善，但安全与关系泛化仍未通过

本轮完成了真实CPU LoRA训练、第三实体词表测试和两模型共256个自主回合。结论是**局部有效、联合目标未解决**：一跳任务的完整四呈现成功从0/8变为8/8，总成功从49/128升到74/128；但违规从15/128增加到27/128，深层与结构变化的完整配对仍全部失败。GPU大批量仍为 **NO_GO**，完整研究目标未完成。通俗解释及数据路线见 [SOLUTION.md](SOLUTION.md)。

修复针对最近小集训练的一个缺口：每组关系反复只使用两套名称。现在同一组关系使用16套名称；第一轮保持不变，之后仅修改名称随机种子。固定组与增广组都从同一旧检查点出发，使用相同18组TRAIN关系、36个状态、14个基础组，相同144步日程、联合损失、优化器、学习率和监督目标。增广组新训练一次；固定组使用已经封存的联合训练检查点。此前“答案位等权”实验没有改善换名结果，因此本轮保留原损失做匹配比较；没有宣称等权修复已有效。

控制检查通过：18组关系各有16个不同的实际名称映射，且均为双射；1,920对训练文本逐条比较，prompt及答案长度无差异；144次更新token总数与固定组一致。第一轮18次更新的损失、梯度范数、token数和监督目标逐项完全相同。回归测试保留了修复前失败与修复后通过的记录。最长单次训练6.154秒，144次训练共572.032秒。

数据没有增加新的训练关系。新增第三套128词实体词表，与原训练及已反复用于开发的换名词表两两不重叠；这不代表基础模型预训练从未见过这些词。每模型评估168条原名、168条旧换名和168条第三词表TRAIN查询，并保留144条正确判断输入下的Worker动作诊断。48个变化配对是动作×呈现单位，含相关重复，不是48个独立任务。

另用新的种子范围生成128个DEV呈现，来自64个语义世界、40个基础组，沿用此前开发过的任务族。每模型评估1,536条固定分支查询、640个状态及128个自主回合；关系翻转、两种呈现、深度和结构条件都匹配。它们是新生成的合成DEV，不是独立外部业务测试；呈现同时改变名称与排列，不能只解释为换名效果。120个呈现存在合规完成路径，8个属于无解控制。

两模型的oracle动作诊断均为零违规、零无效；它只说明给对判断时能正确选动作，不能替代自主表现。所有固定查询和自主查询均无格式无效；自主动作的3个无效记录都只输出了`A`，缺少约定的`ANSWER:`前缀，已按原规则保留为失败。没有用解析宽松化修复分数。

第三词表主面板有一项数值路径限定：虽然文本本身等长，24/168条的初始批次填充宽度与原名面板不同。这不影响同一第三面板上两模型的匹配比较，但需要校准后才能严格讨论模型内换名差异。为此在主实验封存后单独登记了完整布局校准，额外生成672条响应，没有挑选失败样本，也没有更改主门槛。两模型各336条初始填充宽度全部匹配、各168条原名输出逐字复现；第三词表各168条也与原先单独分批的输出逐字一致，解析答案相同，无超时或无效。第三词表配对仍为24/48、22/48。这个有限校准中没有观察到布局影响，不构成所有数值路径都不敏感的保证。详见 [补充计划](WIDTH_CONTROL_PLAN.md)及 [补充结果](width_control/RESULTS.json)。

**不能把原名与换名的差距缩小称为泛化修复。** 差距从19对缩到7对，但原名、旧换名、第三词表三个配对成绩都下降。一跳自主成功是有限进展，尚不能证明模型对所有分支学会了关系规律。

一个重要反例来自固定状态查询：新DEV全部Worker查询中，错误肯定从42/616个负标签增到81/616，错误否定从35/152个正标签降到6/152。一跳Worker的错误肯定也从2增到17。也就是说，上游选到正确路径后，一跳回合可以成功，但未被该路径访问的危险分支仍可能判断错误。因此不能只凭8/8回合成功宣布可靠关系学习。这些是同一固定状态面板上的描述性结果，不能单独证明全部违规增长的因果机制。

失败定位另外登记并保留了版本历史。固定组失败回合的首个次优动作伴随错误判断：Planner31、Source19、Worker21；增广组为35、5、6。各另有8个无解回合没有次优动作。有效安全终止可以包括不完成任务的最小输出，不等同于专门选择Stop。这份定位没有修改训练、主门槛或任务结果，也不是替换判断的因果干预。

主实验全部256回合经原生重放，核对717个动作、1,641个自主查询及640个标签状态，审计错误为0。主实验新增6,246条生成响应，另有480条固定组旧查询/oracle输出按字节复用，不计为新调用。新增生成时间1205.693秒，最长批次1.290秒。完整原始输出、模型、源代码和数据哈希均已保留；复核命令见 [REPRODUCE.md](REPRODUCE.md)。

连同单独的数值校准，本轮共新增 **1个训练检查点、144次更新、6,918条生成响应**，复用480条另计。生成耗时合计1331.471秒，训练耗时572.032秒；这些是记录的计算时段，不包含数据准备和审计挂钟时间，也不是6,918个独立样本。独立复核以拦截写入的方式重算主结果、原生重放和失败定位，均与封存结果逐项一致。

主门槛未通过，原因包括三词表配对未达标、违规非零、深层完整组未通过及动作格式失败。I/L/H标记、指令语法仍固定；外部自然业务规范有效性、跨业务迁移、32步Agent协作均未在本轮解决。每个自主回合最多3个政策动作，不能称为32步协作。此次结果不支持直接扩大当前训练配置；下一步应先检验多跳与未访问分支中的错误肯定，而不是把更多任务完成当成安全学习成功。
