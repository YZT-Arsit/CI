# What this ablation can establish

The state-action abstraction literature explicitly distinguishes preservation of useful policy/value information from preserving every original detail. [Abel et al., AISTATS2020](https://proceedings.mlr.press/v108/abel20a.html) analyze value-preserving combinations of state abstraction and options under specified assumptions. That result is context for asking which distinctions matter; it is **not** a theorem about this implementation, a reproduction of their method, or novelty evidence for grouping the present finite action values.

Here each training state supplies native action values. Let C(a) be the full value-tuple class of action a, and retain invalid-token mass as OTHER. The new actor term compares sums of action probabilities within C. When two equally valued actions exchange probability mass, class sums need not change. Different value classes and OTHER remain distinct. This removes a constraint on which equally valued action is favored, while preserving the original supervised loss and query consistency. Both views retain gradient paths.

Full action JS is stronger than this class-level constraint, but is compatible with an optimal policy. Failure is an empirical question. The intervention also decreases regularization magnitude. If it improves results, this alone cannot identify value semantics as the cause rather than weaker actor regularization. The query-only arm helps localize whether any actor regularization is needed; a future strength-matched study would still be needed for a mechanism claim.

Neither class agreement nor low supervised set loss guarantees greedy success. For example, two optimal actions with probabilities0.3and0.3 can have greater combined mass than an unsafe action at0.4 while the greedy action remains unsafe. Actual free-generation native episodes, not summed good-action probability, remain the primary evidence.

The additional TRAIN-only contract audit found1,920state occurrences but only1,280unique observations; exact duplicate observations have identical labels. Across10distinct role/action/completion summaries, every group has at least one action optimal for every member. Therefore this finite audit does **not** support claiming that a second immediate-safety bit is necessary to select an optimum. The actor also sees the full observation, so summary collisions, if present elsewhere, would not alone prove the full input ambiguous.

The actual repaired training records contain incorrect query maps on44/160Worker presentations in each previous arm;12/160presentations have predicted-positive actions disjoint from the native optimal set. This means some training inputs tell the actor that the best action cannot complete while its target says to select it. It is a potential binding-learning confound, not proof that teacher estimates, separate models, or more query features would fix the system. No new policy architecture is substituted for the requested learned relationship mechanism.
