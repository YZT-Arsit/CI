# KCI V3.1：去除词面捷径的长期知识状态学习开发数据

日期 2026-11-20。原 V3 保持不变。此次 V3.1 是完全虚构业务与给定 CI 规则的可执行开发环境，**不是论文盲测、真实企业数据、经社会规范专家批准的数据或训练成功的 LLM 策略**。

## 一、Gate A 已完成的事实

旧 V3 虽有真正的长期 Q-star 最优动作 Flip，却能被简单的“同主体 + S01..S06 + 未授权”规则以 210/210 完美预测，且长期价值差始终为 +0.40 或 −0.05。

V3.1 对原来的七类非同构知识图进行事实位置置换。每一项新机制同时有：
- 同一主体、同样使用正常 S01–S06 真实线索，相关历史会与未来任务必需事实拼出受保护关系；
- 同一主体、仍使用 S01–S06 正常线索，但根据公开知识图和未来必需事实不构成受保护关系；
- 其他主体使用相同真实事实类型、同一主体 Hold 历史、以及单独变化授权的对照。

模型可见的任务、权限、预算、业务条件、动作菜单在严格历史配对中保持不变；只有已经送达 R 的历史消息内容不同。所有模型看到的推理规则与证据合同均属于公开给定条件，不靠隐藏 evaluator 判断。

## 二、实际数据规模

- 7 种知识规则图、21 个业务×知识图根、63 个受控机制配置。
- 315 个 preflight 真实模型可见状态，630 条 OPEN/SKIP 同状态真实原生行动续行。
- 正向长期价值差 37 种，负向长期价值差 18 种。任务确实需要 1、2、3 项来源检查；保护初始化需要 2、3、4 步，公开步成本六档。
- 2030 条原生最佳行动轨迹上的多角色模型可见状态，Coordinator、DirectoryAgent、OrderAgent、RecordsAgent、ComplianceAgent 全部出现。
- 72 条严格训练知识图的平衡早期动作偏好（OPEN/SKIP 各36），485 条仅训练图的多角色原生最优示范。
- 另有7种知识图的真实 Broker 路径；M 先接收实际源事实，然后决定向 R 发送原始消息还是证明。7种原文转发路径真实触发 CI 违规；7条转发证明路径安全完成任务。

注意：以上原生轨迹并非语言模型 on-policy 交互。全部长期值是确定性有限原生环境的 Q-star，不是 Qwen4B/7B Q-pi。

## 三、严格类平衡主评测，而非混报315个偏负类状态

每个机制只取 related 和 same_entity_safe 两条**同主体、正常词表**历史。主评测一共126个状态，OPEN 正类63、SKIP 负类63，所有合法行动可见。

| 模型可见信息的 CPU 决策策略 | 最优首动作准确率 |
|---|---:|
| 永远 OPEN | 63/126 |
| 永远 SKIP | 63/126 |
| 旧 V3 审查中的主体+正常编号+授权三条件词面规则 | 63/126 |
| 仅主体或仅正常编号 | 63/126 |
| 计算公开规则闭包和未来任务必需信息的显式推理 | 126/126 |

实际策略不是只看第一步后由 oracle 接管：本版额外通过真实模拟器执行了 126×7=882 次规则策略轨迹，记录实际终局、隐私结果、步骤成本和后悔值。**固定 OPEN 仍然能够安全完成全部主要场景，因此不能只看安全完成率；必须同时报告成本、长期动作最优性和 regret。**

独立的浅层词袋和字符 n-gram 分类器仅用训练知识图拟合，开发 8/18、探索性测试 18/36，均未达到简单词面上的有效泛化。训练集只72个平衡状态，非常小；不能据此声称任何神经学习方法的不可行性或优越性。

按整个知识图家族划分：训练4图/开发1图/探索性测试2图。同一任务的所有历史变体均在同一拆分；探索测试图已经用于开发审计，不能视为严格盲测。

## 四、可训练性和学习数据等级

真正的长期同状态OPEN/SKIP价值对比、完整终局证据及原生轨迹保存在 EVAL_ONLY 文件。TRAIN_ONLY_BALANCED_NATIVE_OPTIMAL_ACTION_PREFS.jsonl 中的72条偏好是精确原生最优行为候选，不能冒充当前模型策略 Q-pi 的偏好；如做 DPO/监督训练，必须准确声明它是离线 oracle 最优动作监督，并用独立模型行动实验评估可学性。

TRAIN_ONLY_NATIVE_MULTIROLE_ACTION_DEMOS.jsonl 是485个来源于原生最优脚本的多角色训练示范；既不是多 Agent 自主 LLM 的轨迹，也没有模型产生时的旧策略 logprob/KL 信息。多角色阶段仍主要由简单的读源/安全验证/提交构成，开放域语义理解和工具失败恢复尚不成熟。

TRAIN_ONLY_BALANCED_NATIVE_OPTIMAL_ACTION_PREFS.jsonl：72条平衡训练候选。
TRAIN_ONLY_NATIVE_MULTIROLE_ACTION_DEMOS.jsonl：485条多角色训练示范。

V31_BROKER_MULTIROle_P1_02 是额外P1多接收者业务路径验证，不与严格固定业务条件的长期Q-star Flip混算。

## 六、结论和待验证内容

**Gate A 的受控机制验收成立：严格历史Flip、同状态完整续行、非固定奖励差、旧V3词面捷径失效、多角色状态及真实路径证据均已验证。**

但这不是“模型学会 CI”的证明。模型自主策略 Q-pi、真实任务自然语言、独立业务规则、封存的测试集及学习收益实验均仍然缺失。显式读取全部已公开图的规则规划器依旧100%，属于不可删除的强基线。Gate B 需要同一冻结模型、相同格式与训练预算下的真实策略实验，不能把原生oracle当成训练后模型。
