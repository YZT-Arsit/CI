# KCI-Align 方法验证与关键修订（2026-11-22）

本轮以 `KCI_Align_ACL_Draft.pdf`、V4 数据和已有模型原始产物为依据。日期按用户时区；部分原始产物目录使用服务器的 `20261123`。保持 main。其他 AI 的代码、模型和历史结果没有覆盖；GPU 测试在独立目录 `/root/kci_method_audit_20261122` 进行，启动前确认无计算进程，结束后也确认无计算进程。没有读最终封存测试、没有重新训练、没有停止他人的进程。

## 1. 判断：方向合理，但“理论上必然超过 SFT”不成立

CCE 的合理性是：在同一合法观察和同一真实前缀处，比较候选动作执行后可验证的未来后果。DPR 的合理性是：针对模型实际到达的失败状态，找出能够修复后续任务的决策，避免把下游失败一概归罪于上游合法动作。两者都可能弥补仅模仿成功轨迹时缺少的监督。

但 SFT 如果已经获得完整历史、正确关系、所有相关状态的最优示范，也能学到同样的最优策略。一个两动作、收益分别为 0 和 1 的例子中，最优 SFT 和精确 CCE 都得到 1；严格超越没有空间。因此不能把“监督信息可能更丰富”写成“损失函数必然更优”。

[DPO 原论文](https://arxiv.org/html/2305.18290v3)建立的是偏好模型与参考策略约束下的优化关系，并没有给出对任意 SFT 的严格优势保证。[DAgger 原论文](https://arxiv.org/abs/1011.0686)解释了序列任务中模型自身访问状态的分布偏移，也有额外假设；不能直接当成 KCI 的定理。

**可以成立的有限命题：**在相同、已经验证的安全可行候选集合上，设标量任务价值估计满足 `max_a |Qhat(a)-Q(a)| <= epsilon`，选出的动作满足 `Qhat(ahat) >= max_a Qhat(a)-eta`。那么：

`Q(a*) - Q(ahat) <= 2*epsilon + eta`。

证明是把差分拆成 `Q(a*)-Qhat(a*)`、`Qhat(a*)-Qhat(ahat)`、`Qhat(ahat)-Q(ahat)` 三项，逐项上界分别为 epsilon、eta、epsilon。只有基线在该状态的真实劣势大于这个上界，才可推出严格局部改善。

边界很重要：这不是神经网络训练收敛定理，不保证测试分布泛化，不把未知安全性当作安全，也不把多目标词典序直接变成一个标量。若 Q 是固定 continuation 策略的 QπC，结论只约束先选一步再执行 πC 的策略；部署成另一策略后不能直接沿用。全流程还要控制状态覆盖、后续策略改变和价值误差。

## 2. 本轮确认并修复的真实实现问题

`HFActionPolicy` 训练 4-bit LoRA 时调用 PEFT 的 `prepare_model_for_kbit_training`，把非量化 embedding、norm、输出 head 等升为 FP32；原先冻结基座和保存后的 adapter 重载路径没有做同样处理。最后对 logits 调用 `.float()` 无法恢复前向过程已丢失的精度。

修订 `code/kci/agent_rl/hf_policy.py`：

- 默认 4-bit 推理采用与训练一致的非量化层精度，在装载 adapter 前处理；冻结基座也采用同一路径。
- 推理不启用梯度检查点，也不保留可训练参数。
- `kbit_inference_precision="legacy"` 可显式复现旧评价路径。策略标识包含精度模式；新保存 adapter 附带 `kci_runtime.json`。
- 没有修改 reward、CI 判定规则、训练样本、LoRA 权重或论文中的 CCE/DPR 损失。

**后续训练／评价必须统一路径；旧数值结果保留为 legacy，不能与新路径无标注混合。** 未将修复覆盖到其他 AI 正在使用的服务器项目；本地默认已修复，远端仅隔离副本用于复核。

这说明数值路径是效果不稳定的一个已证实因素；不能据此声称安全性或关系泛化已改善。DEV 的总准确率相同，错误结构却变了：原文两个危险发布状态现在都失败。自主协作的实际历史由此前模型动作改变，与固定发布状态不是严格配对，不能拿自主轨迹零违规抵消这两次失败。样本只来自两个开发任务，重复开发集测量不是新的独立测试，也没有统计显著性结论。

## 4. 为什么效果还不明显

**第一，实际模型实验还没有完整验证论文方法。** 最新修复主要是小规模发布状态监督学习。Phase2 的 12 根任务、60 世界及语言变体提供了更丰富的训练材料，但不等于这些材料已经被当前模型有效使用；当前受审计模型仍只训练 3 根任务的 9 状态。34 个独立偏好扩成 204 条语言／顺序记录，也仍然只有 34 个独立比较。固定人工后缀和有限环境最优解不是模型真实 continuation 的 Qπ。

**第二，DPO loss 下降不能替代行为验证。** 本轮给出可复算反例：参考策略对好动作的概率 0.001，训练后提高到 0.01，beta=2 时 DPO loss 从 0.693147 降到 0.009773，但 greedy 仍选坏动作。这不说明 DPO 无效；它说明有限训练时相对参考的进步不能当作绝对动作正确。当前实验中“全 RAW”或“全 VERIFY”的退化，必须用危险／安全／授权三类正确率和完整配对判断。

**第三，独立结构和流程监督不足。** TRAIN 已拟合，不代表换符号仍会执行关系规则。改名 DEV 仍 6/10；其他阶段未覆盖，流程失败不能靠继续加大发布决策的 loss 权重来保证解决。之前 grouped CE 使用 864 次训练候选前向，旧逐状态 CE 是 288 次；不能把两者差异全部归因于分组策略。

**第四，便宜的采样共识不是置信保证。** `policy_cce.py` 和 `state_directed_cce.py` 目前的少量 continuation、均值间隔和符号共识，是启发式信号筛选。它们不能直接充当论文所需的统计证书。对每条 return 在 [-1,1]、独立 seed 配对，双侧 95% Hoeffding 差值半径为 `sqrt(8*log(40)/n)`：n=4 时 2.716，n=16 时 1.358。这个保守例子说明“小样本观察一致”与“已证实微小价值差”是两回事。也不能因此断言必须用此界或固定 128 个样本；需要预先定义有效统计方法，证据不足时弃权。

## 5. 提纲挈领的方案修订

### A. 先建立有完整流程能力的强 SFT 起点

用已有、经原生执行核验的 TRAIN 成功轨迹补齐各角色阶段，再保留危险／安全／授权的分组发布训练。保留合法业务完成，避免全部拒绝带来的表面安全。先在 TRAIN 上检查每阶段严格动作正确和端到端成功，再进入未来价值学习。这不是取消 CCE/DPR，而是防止后续流程根本不会执行，导致所有候选的实测 Qπ 都接近失败。

不要把 DEV 的 DG35 失败直接搬进训练；本轮只是定位缺口。用 TRAIN 同类角色阶段及 TRAIN 策略实际访问状态构造修复样本。

### B. 让关系变化与符号、长度、资源变化真正分开

仅对 TRAIN 做经过原生语义校验的实体／来源符号双射改名、规则顺序改变和等价历史变换。每个任务同时包含：

1. 改历史关系，但保持消息数量、长度分布和资源条件匹配，正确动作应翻转；
2. 只改实体名或无关消息，正确动作应保持；
3. 改授权范围，允许披露的动作应相应改变；
4. 改真实任务依赖，检验同样信息在不同任务中的后续价值；
5. 分别扫描真实 deadline、私有验证成本和无语义 padding，防止模型只用流程长度判断。

资源条件本来就可能合法地改变价值；不能强求所有成本变化后排序不变。关键是固定资源时关系干预仍有效，固定关系时资源影响符合真实执行结果。按原始来源、关系结构和任务模板分割；等价变体不计作新的独立任务。最终封存集继续不参与开发。

### C. 让 CCE 和 DPR 产生可执行、可归因的新监督

CCE 在同一完整状态上下文处克隆候选，冻结同一 continuation 策略和随机性协议，分别记录安全、任务成功和实际成本。完整状态身份须包括任务、规范、环境版本与观察，不能只依赖可能跨授权世界重复的 native hash。`Q*`、`QπC`、`Qπθ` 分别标注；UNKNOWN、失败搜索、成功 witness 不能互相替代。

DPR 从 TRAIN 模型真实失败前缀找可修复决策，验证替代动作及后续任务确实能完成。无法挽回的前缀只标记安全退出；不得虚构胜者。保留上游合法动作，不对失败轨迹所有动作统一负反馈。

### D. 用同数据强 SFT 对照定位贡献

先做小规模而不是全套大训练：

| 对照 | 数据与目标 | 回答的问题 |
|---|---|---|
| 强 SFT | 完整阶段的 verified TRAIN 正例与关系控制 | 基础任务能力达到什么水平？ |
| 扩展数据 SFT | 将 CCE/DPR 验证出的同一批正确动作也交给 CE | 增益是否只是更多、更好的监督？ |
| 同数据偏好训练 | 同一状态池、同一比较证据、匹配训练预算 | 偏好目标本身是否提供额外增益？ |
| CCE/DPR 迭代 | 逐轮冻结策略、更新实际失败状态与后果证据 | 自身状态覆盖和长期信用是否有增益？ |

分别计入采样、验证和训练开销；同样 96 步不等于同等计算。若同数据 SFT 追平，应如实把贡献定位为监督构造／状态覆盖；不能硬写成损失函数创新。SFT 起点加偏好训练若遗忘工作流，可再独立验证成功轨迹回放，不能未经对照就叠加新的正则项。

建议论文替换表述：

> CCE and DPR are intended to improve supervision coverage and decision-level credit assignment under evolving recipient knowledge. They do not guarantee strict dominance over an equally informed supervised learner. We evaluate their incremental value against computation-matched SFT trained on the same verified states and preferred actions, and separately test the value of policy-induced repair data.

## 6. 验证、交付边界与下一步

新增 CPU 回归使用真实 tiny Qwen2/PEFT 的保存和重载，只替代 CUDA/4-bit 权重装载；不把它当成 NF4 GPU 测试。独立 4B GPU 复核补齐了真实量化路径证据。新集成测试在子进程中运行，避免污染仓库原有的固定 tokenizer 依赖检查。

最终全套结果：**434 passed，395 subtests passed，41.12 秒**。首次全套检查曾有 18 个 tokenizer 隔离错误，原因是新测试在收集阶段导入了外部 tokenizer；已经改为子进程隔离并重新通过全套。最初一次 GPU 探测指向未完整下载的同名权重目录，未完成加载；改用训练元数据记录的 `-ms` 目录后得到上述结果。失败日志保留，未把失败计入成功实验。

`FINITE_METHOD_CHECKS.json` 还保存最优 SFT 反例、DPO 低 loss 反例、592 个有限网格条件界检查和长流程误差累积示意。网格检查不代替数学证明，示意值不是实测模型结果。

**本轮已完成：**方法边界澄清、一个已验证的核心实现修复、CPU 回归、真实 GPU TRAIN 重载校准、固定模型 DEV 和自主流程复测、可复算理论诊断与论文方法修订提纲。

**尚未完成／不能宣称：**CCE+DPR 已超越同数据强 SFT、未见关系结构泛化、自然业务规范的独立外部有效性、足够根任务与多随机种子的稳健收益、32 个有意义协作步骤的能力。没有新建或扩大训练数据集；产出的是审计与诊断数据。

当前适合投入**有限、计算匹配的完整流程 SFT 与 CCE/DPR 信号试验**，还不适合把大批量实验作为“已证实方法优势”的扩大验证。先把剩余缺口定位清楚，比继续堆更复杂的损失更有价值。
