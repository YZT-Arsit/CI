# KCI-Align 四小时限时验证报告

2026-11-24 · Qwen3-4B-Instruct-2507 · 单张远端 NVIDIA GeForce RTX 4080 SUPER，设备报告 32,760 MiB 显存

**研究裁决：跨任务方法有效性未通过预设门槛。** 完整方法在两个主环境都超过了本轮的整轨迹 DPO。与仅即时 CI 相比，原协议下证据交付的安全成功率增加 7.6 个百分点，直接违规增加 10 次；关系聚合的安全成功率下降 2.3 个百分点。DPR 相对缺少 DPR 的训练臂提供了局部收益。原业务终局测试、数值复核和第三数据源迁移各自限定了这个结论。

![初始协议的配对场景效应](../artifacts/20261124_cce_dpr_validation/analysis/paired_effects.png)

完整方法相对即时 CI 新增的 10 条直接违规中，9 条是邀请新成员并暴露已有工作空间历史。9 条发生时，两种窄范围导出通道均已不可用。剩余 1 条是向无权接收者转发证据。这一描述来自冻结轨迹的逐步对照。在全通道可用的反事实控制里，即时 CI 和完整方法在危险、合法两种历史下都没有选择邀请；关系任务中，两者在危险、合法及已授权条件下也都没有选择公开受保护投影。选择另一条合法路径有时仍能完成任务，因此这些统计衡量合法披露意愿，单独报告。

在冻结基座实际失败并存在可验证修复的 DEV 状态上，以场景等权统计，按“即时 CI / CI+CCE / 完整方法”排序，证据交付为 95.2% / 66.1% / 92.2%；关系聚合为 100.0% / 94.4% / 94.4%。固定失败状态上的局部纠正率和从初始状态执行的团队成功率描述不同的问题。完整方法在原始菜单的证据交付初始动作上，严格参考偏好的一致率为 80.3%，一步路由基线达到 90.9%。关系 DEV 仅 9/16 个初始状态形成严格参考排序，9 个均为成本差异，其余保留为平局或证据不足。

## 数值复核

原实现使用不同长度的批次缓存冻结参考，实际 DPO 更新按单个观察前向。零 LoRA 的首步损失与理论值 ln(2) 最大相差 0.0186。事后数值审计固定九个原训练臂/种子各自的全部 96 次更新和样本 ID，改由相同的单样本、训练模式、可微前向路径在零 LoRA 处计算并冻结参考。批量参考与匹配参考的动作对数赔率绝对差中位数为 0.250，95 分位数为 0.750。九次匹配运行的首步损失均通过 1e-5 的恒等检验。评测沿用已使用的 DEV，各原始协议结果保留。

|路径匹配复跑|证据交付 STSR|直接违规|关系聚合 STSR|新增推断违规|
|---|---:|---:|---:|---:|
|仅即时 CI|62.5%|1/480|52.7%|0/384|
|即时 CI + CCE|58.0%|7/480|39.2%|0/384|
|即时 CI + CCE + DPR|67.8%|16/480|52.3%|0/384|

|路径匹配复跑的配对比较|证据交付 ΔSTSR [95% 区间]|关系聚合 ΔSTSR [95% 区间]|
|---|---:|---:|
|完整方法减去仅即时 CI|+5.3 [-2.3, +13.4]|-0.4 [-15.2, +12.9]|
|完整方法减去即时 CI + CCE|+9.8 [+5.9, +14.4]|+13.1 [-1.7, +27.9]|

匹配复跑后，完整方法相对即时 CI 的两个场景级区间仍跨零，证据交付的直接违规由 1/480 升至 16/480。每个种子原先对 CI、CCE 各抽样 192 次，加入 DPR 后对三类数据各抽样 128 次。这个固定总更新数的比较中，证据交付的增益区间下界高于零，关系聚合的区间跨零。这些复跑共用原 DEV 场景。

更换候选动作排列后，匹配复跑的完整方法相对即时 CI 的差值依次为 -0.4 和 -10.4 个百分点。原协议同一比较在换序后的差值为 +1.5 和 −11.5 个百分点。数值审计覆盖三个同状态核心 DPO 臂，整轨迹 DPO 与原业务训练沿用其登记的参考实现。

## 原始 PiSAs 业务决策

先将主实验适配器零样本迁移到 11 个留出原始业务场景。合法决策码、原始正确答案、必要证据、直接披露和实际收件共同决定结果。完整方法安全成功 7/33，冻结基座 5/11，整轨迹 DPO 17/33。这 11 个场景与证据交付 DEV 共用来源，分属稿件提交、博物馆外借和无人机飞行准备三种业务。

另行使用 89 个 TRAIN 原业务场景训练，得到即时 CI 181 对、长期偏好 29 对（15 个根）、实际失败 DPR 10 对（10 个根）。51 个长期比较并列。冻结参考安全完成了 58/89 个训练场景。每个训练臂使用三个种子，每个种子 64 次更新。

完整方法相对即时 CI 的原始业务 STSR 差值为 -36.4 [-57.6, -15.2] 个百分点。在 11 个场景中按种子平均，完整方法胜 0 个、平 4 个、负 7 个。相对 CI+CCE 的差值为 -54.5 [-75.8, -33.3] 个百分点。完整方法在 32/33 次执行中收齐证据，只有 6 次答对。10 对 DPR 中，7 对纠正了过早提交，3 对改变了请求证据的顺序。

**长期偏好的机制核查。** 29/29 对的两个分支最终均合规且收齐同一批必要证据。终局演员状态中仅收件顺序发生改变，随观察哈希生成的动作菜单也随之改变。两因素交叉重放冻结基座后，18/29 对仅菜单位置改变了答案，1/29 对仅收件排列改变了答案，10/29 对两种因素均影响至少一个配对条件。该原任务数据验证了固定续行模型的排序敏感性，尚不能据此证明 CI 约束改变了后续任务可行性。

## 第三数据源 CI-Work

训练没有使用 CI-Work。用原始标签评估 10 个预分配 DEV 任务，覆盖五种信息流方向。每个任务改变证据排列三次，模型自由生成 JSON 证据集合，全部 480 份回答均可解析。冻结基座精确选择必要且仅必要的证据 24/30；即时 CI 为 71/90，CI+CCE 为 69/90，完整方法为 69/90。完整方法在 13/90 次选择中纳入敏感材料，即时 CI 为 9/90。这里衡量业务材料选择，外发消息没有实际发送。

## 证据边界与论文处理

- 可报告观察到的局部效应、场景级区间、对应的违规代价与路径匹配复核。主表的失败门槛、确定性规划器、原始任务终局以及 CI-Work 上未观察到迁移增益的结果，应一并保留。
- 现有数据没有支持完整方法稳定优于即时 CI，也没有建立开放式多代理对话、真实组织规范或 32 次有效协作下的收益。关系环境中的稀有集合交集在 DEV 缺少样本。原任务评价覆盖决策码，调度和分派任务仍待验证。整轨迹 DPO 是配对终局偏好对照，未复现 PrivAct。
- 下一项直接针对论文机制的验证，应优先选择能重放出**同一上游动作因实际收件权限而改变未来合法可达性**的独立业务场景；同时固定终局动作表示。当前原业务的 29 对顺序敏感比较不宜作为这一主张的正例。

## 可复现性

主协议训练集含 251 对即时 CI 偏好、377 对 CCE 后续偏好，以及 138 对来自冻结基座实际失败轨迹的 DPR 修复。138 对修复来自 102 个原始训练场景，均在同一可见前缀重放失败动作与成功替代动作。主比较在同一批根上另构造了 174 个整轨迹偏好样本和 563 个成功轨迹监督样本。[训练数据审计](../artifacts/20261124_cce_dpr_validation/TRAIN_AUDIT.json)

主试验用 183 个独立 TRAIN 来源根、251 个配置、21 个不重叠 DEV 来源根。逐字节检查中，15 个主适配器 DEV 上所有非平凡选择的可见提示均未命中训练监督提示。主比较每臂 96 次更新、有效批量 4，LoRA r8/alpha16，q/v 投影，学习率 8e-5，DPO β=0.2。三种子控制了更新顺序和 LoRA 初始化。训练阶段按类型分配更新机会，再在类型内对来源根均匀采样。同样更新数下，各方法的 token 数及计算时间不同。15 个主适配器的可微更新合计 26.7 分钟，未计数据准备、参考前向和评测。

本地重放了 10,080 条主实验及规则对照轨迹、数值复核 5,184 条轨迹、308 条原业务 DEV 执行，并审计 36 个不同适配器。已核对逐角色动作、收件状态、任务终点、修复来源和远端文件哈希。所有正式结果为 DEV 证据，保留锁定测试集用于后续独立确认。
