# KCI-Align 论文实现与 RTX 4090 验证

2026-11-24 在新实例的 RTX 4090 上，用同一个 Qwen3-4B-Instruct-2507 执行所有角色，跑通了原生轨迹采集、CCE、DPR、式 (14) 的共享模型更新和适配器重载。验证覆盖有可执行交付与推断规则的 v8 TRAIN 子集。新增长期监督与修复监督都能减少中止，但三种含这些监督的模型在九个开发世界上作出了相同决策，其中一个世界发生了新增推断违规。这个检查点未达到任务与隐私同时可靠的要求。[论文 §§3–5、附录 C](../KCI_Align_ACL_Draft.pdf) · [逐臂核对](../artifacts/20261124_paper_native_gpu_18828/comparison.json)

## 模型实际学到的监督

| 论文要求 | 本次实际执行 |
|---|---|
| 交付与知识更新，式 (2)–(5) | 从同一原生状态克隆候选，接收者成功收件后更新知识。Phase2 用按主体与收件人分组的 Horn 闭包，关系任务用来源表的一跳、两跳连接或单例交集。分别检查直接禁止传输与未授权新增推断。候选分支不会改变实际前缀。 |
| CCE，式 (9)–(10) | 给定首动作，分别计算冻结共享模型与固定角色可见参考策略的续行结果。对同一环境的外生事件逐分支按概率求和，时域为 24。保存违规、任务成功、安全成功、成本及可重放的安全成功路径。两条即时合法动作只依据固定参考策略的可比较结果排序，优先降低违规，再提高安全成功，最后降低成功成本。参考路径只证明该路径可行。 |
| DPR，§4.3 | 从当前共享模型实际失败的角色轨迹回溯到同一角色、同一可见状态的决策。负例为执行过的动作，正例要可执行、有改进证据且有安全成功见证。参考策略发起的轨迹与强制前缀只用来采 CCE。 |
| 共享 DPO，式 (11)–(14) | 收集期间冻结模型；DPO 分母取更新前同一适配器的动作分数。训练与推理都在角色可见的原生语义动作菜单上选一个动作，使用同一模型。每个纳入的硬标签都有可验证证据，权重取 1。三类监督的系数默认各为 1。 |

有限动作实现用原生可执行菜单产生候选，每个动作映射为规范排序后的一个选择符。授权规则按环境明文规定，事实来自签名模板或结构化投影。本轮没有验证开放自然语言语义抽取、人类对争议规范的判断或搜索全局最优策略。起点是上一轮企业与业务共享适配器，新动作接口与当时不同，起点分数是在新接口上重测的。[环境与规范](../code/kci/paper_worlds.py) · [双策略续行与修复](../code/kci/paper_alignment.py) · [动作概率与损失](../code/kci/paper_policy.py)

## 数据与监督核对

- 源索引取 v8 TRAIN 的 `PHASE2_REAL4B_DPR` 与 `REL_SQL_DYNAMIC_CI_STRICT`，从原始环境重新生成交付、监督和任务结果。历史企业静态选择、直接 ACL 结果继续保留原含义。所有可重建源共 92 个任务根、287 个世界；完整打包入口已验证为训练 77 根／234 世界、开发 15 根／53 世界。
- GPU 验证使用事先固定的小面板，训练 7 根／20 世界，开发 3 根／9 世界。按来源根分组，同根的授权、顺序等变体不跨本次训练／开发边界。这个边界仅适用于本次更新，不能证明预训练或历史热启动从未见过相关任务。官方独立留出未用于选模。开发面板覆盖 Phase2 与一跳／两跳关系任务，单例交集只进入本次训练面板。
- 每个训练世界收集 1 条共享模型自主轨迹和 2 条用于扩展状态覆盖的参考轨迹，合计 60 条。CPU 重放核对了 370 个决策状态、944 个候选转移分支、521 个带安全成功见证的候选，以及两套冻结续行值。19 个决策状态形成即时 CI 偏好，342 个形成长期偏好，9 个形成下游修复；78 个固定参考值相同的合法动作比较被舍弃。
- 共 29 条即时 CI、646 条长期、9 条修复。9 条修复来自 9 条真实失败轨迹，其中 2 条纠正即时组合披露，7 条纠正过早中止。全部修复的同状态正负动作也出现在前两类监督中，去重后总计 675 个动作比较。DPR 在这个数据集上提供了真实失败来源和重新采样权重，没有贡献额外的不同正负动作。[源清单](../artifacts/20261124_paper_native_gpu_18828/packet/manifest.json) · [原生重放审计](../artifacts/20261124_paper_native_gpu_18828/native-audit.log) · [偏好及重叠](../artifacts/20261124_paper_native_gpu_18828/comparison.json)

## 一次组合披露怎样发生

P207 的包名互换变体中，两个模型都把包 B 合法交付给目标收件人 R。共享起点在合同核查时中止。更新后模型继续办理，最后 SourceAgent 将原始 S04 交付给 R。R 结合已送达内容首次推出受限关联。该次原始传输本身未触发直接披露规则，但新增推断违反了当前用途的规范。一个根的五个变体中有一个违规，三个根等权汇总后是 6.67%。

同一源角色在这个确切状态还可以选择 `SEND_RAW_BROKER`。重放该动作并由固定参考策略续行，安全任务成功率为 1；提前跳过私有通道也仍有这条合法路径。这把错误定位到了最后一次路由，且说明仅降低中止率不足以保护收件历史。后续可在**训练根**上平衡三种真实失败类型（推断违规、直接违规、过早中止），为每种修复匹配“相同动作在获授权或缺少关键历史时合法”的对照。直接违规需要另有源规范与执行见证。该调整的收益仍待新开发根验证。[两套实际角色轨迹](../artifacts/20261124_paper_native_gpu_18828/anomaly.json) · [同状态替代动作重放](../artifacts/20261124_paper_native_gpu_18828/anomaly_alternatives.json)

## 复现

在仓库根设置 `PYTHONPATH=code`。验证使用现存的 v8 源文件、Qwen3-4B 基座、起始适配器和一个新的输出目录。在 Linux 上可运行以下命令，环境变量分别指向源目录、基座和起始适配器。完整源队列可用 `prepare --cohort full` 生成；本表使用默认验证面板。

```bash
export PYTHONPATH=code
python -m kci.paper_run prepare --research "$RESEARCH_ROOT" --output packet
python -m kci.paper_run verify --packet packet --base "$MODEL_BASE" --adapter "$START_ADAPTER" --output full --steps 16
python -m kci.paper_audit packet full
for arm in ci ci_future ci_repair; do
  python -m kci.paper_run ablate --packet packet --base "$MODEL_BASE" --adapter "$START_ADAPTER" --collection full --arm "$arm" --output "arm_$arm"
done
```

执行代码与源清单有 SHA-256 记录。完整模型保存后重新加载，逐世界核对了权重、动作映射与指标。本轮覆盖论文第 4 节在有限原生环境上的实现与单次更新；论文第 5 节的独立任务基线、多种子估计、开放文本与跨域泛化仍待验证。[运行配置](../artifacts/20261124_paper_native_gpu_18828/run02/config.json) · [完成记录](../artifacts/20261124_paper_native_gpu_18828/run02/complete.json) · [入口](../code/kci/paper_run.py) · [重放审计](../code/kci/paper_audit.py)
