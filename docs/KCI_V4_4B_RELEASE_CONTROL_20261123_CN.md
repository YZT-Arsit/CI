## A. 本轮结论与门槛

**数据标签和同状态奖励监督可用，但这轮字母动作策略未形成历史条件化 RAW/VERIFY 的稳定双向行为。**

- 四个模型在训练根都只有 **0/3** 个独立历史翻转配对达到“危险与合法历史两侧均正确、且正常/换位两种菜单都正确”；
- DG34/DG35 开发根都为 **0/2**；因此**不能**说“训练已学会，仅新图不迁移”；
- Action CE 在训练根和开发根都退化为始终选择 RAW，造成危险侧本不该披露时直接违规；
- DPO 中两种顺序严重分离：DG34/DG35 正常顺序选 RAW，交换菜单顺序后选 VERIFY，**10/10** 改变语义动作；
- 因**训练状态稳定拟合门槛未达到**，没有启动 CCE/DPR 长期增量实验，不能声称二者有或没有长期增益。

这轮是完整的阴性对照。正式研究选择是先在**不改变 V4 标签和 native evaluator**的前提下，诊断动作表示、独立场景覆盖和目标函数的关系；DG36 必须继续封存。

## E. 第三个任务的分流判断

**门槛失败。** 当前 CE 虽能让菜单换位不改变动作，却在3/3训练根危险侧选 RAW；DPO 在开发10/10状态仅交换位置就改变语义动作。没有任何新策略达到训练根历史双向 **3/3 且两种菜单都正确**。

**不能继续声称：**

1. 模型已经在训练根学会历史、只是未见图泛化不好；训练端首先就未通过。
2. 奖励标签不正确；V4 原生审计已验证同状态可信即时判决与固定成功续行。
3. 更大的模型必然解决，或 4B 容量必然不够；这轮没有排除动作表示、样本覆盖和优化配方的因素。
4. 现在已有 CCE 或 DPR 的增量收益；两者在本轮根本未进入训练，冻结同一下游真实4B Qπ 的 A/B 长期续行也未执行。

**主要失败证据排序**：

- **直接证实：动作位置/优化捷径。** DPO 对菜单位置高度敏感，CE 只学会多数 RAW 类别。即便提供原始正常/换位两种记录，字母 token 动作接口依旧不保证语义条件化学习。
- **明确存在、但尚未单独归因：监督覆盖有限。** release 仅9个独立比较、3个训练根（危险:合法 3:6），危险/合法/授权每根各1个；不能把18个换位记录当18个独立监督。DG34 的 OrderAgent 未在本轮 release 训练角色中，DG34/DG35 又均是未见图机制，但因训练未拟合，**现在无法判定它们是主要失败根因**。
- **目前不支持判为首要根因：数据标签错误或模型容量不足。** V4 prompt 包含真实送达历史、授权与完整公开推断规则，原生动作本身已被独立复核；现象是模型没有将可见知识转化成正确动作。
- **仅一个 seed，有限独立根**；可解释的训练失败不是统计上关于整个4B模型族的不可学习结论。

**下一步具体顺序（独立待办，不在本轮用DG34/DG35反复调参）：**

先保持 V4 标签、相同合法动作和相同历史输入，做针对字母位置捷径的**语义动作评分对照或固定动作 ID 表示**，并以训练根独立双向配对为首个门槛；若训练稳定拟合再转查图结构/角色迁移。只有局部双向决策确实可学并在合理开发根出现改进后，才冻结同一4B下游团队，执行 A/B 同状态合法动作的真实模型策略续行、记录未来违规/合规完成/成本，对照有限环境 Q\* 并在等预算条件下比较 CCE、DPR、简单 CE 的增量。DG36 保持最终封存，不用于开发挑选。
