# KCI-Align：统一研究与实验设计（总方案草案，2026-11-25）
状态：供研究者审阅的总方案，不是新增 GPU 任务或自动执行命令。现有 process_policy 和 readout_generalization 冻结协议继续完成；既有阴性裁决不改。后续正式实验应以审阅确定后的本方案替代逐轮追加式 handoff，避免重复开工。研究题目保持 KCI-Align: Learning Contextual Integrity under Evolving Recipient Knowledge in Multi-Agent Systems。

## 1. 固定科学问题和主张
研究对象：共享参数、角色条件化的实际任务执行模型。规范在每个 episode 内固定，接收者知识随真实交付演化；当前合法行动可能改变后续安全任务路径。给定合法角色可见观察，学习既遵守动态 CI、又完成合法任务的策略，不依赖测试时外部 oracle 替代行动选择。
H1（问题证据）：控制任务、规范、当前候选和无关因素时，真正改变接收者知识能够改变当前合法性，或改变当前同等合法行动的未来合规可达性；已有训练方法的真实行动尚未充分应对这些变化。
H2（方法主张）：在共享数据来源、角色观察、原生环境、可用动作及明确预算下，显式知识转移相关监督能够提高未见来源的动态 CI 决策及实际协作，而不只是整体降低披露。
H3（机制及范围）：区分知识相关监督的收益与额外监督密度、候选计算量、训练步数或一般推理训练的收益；检查跨来源、跨知识机制、自然语言接口及成本。H3 为 H2 的解释与范围，不是另外一篇论文。
不将静态/动态区别或普通线性读出本身当作算法创新；不把 CCE/DPR、蒸馏、线性读出全部预设为最终方法。当前有限可执行环境不代表任意开放世界安全保证。

## 2. 一次性组织数据资产与评价合同
核心文件 D:/research/kci_supervision_alignment_20261123/d_future_core_20261124/D_future_core_multisource_v2/D_future_core.jsonl：3559 conditional reference pairs，940 split groups（1726 representative source roots，不是独立样本）。ProofWriter 1265/473、Deal or No Deal 1837/344、MultiAgentPrivacy 313/87、PiSAs 144/36；SUCCESS 3360、PROTECTION_COST 199。业务补充 133 task-only rows/71 source-based controls；额外 V9、relation/temporal/scope/CIWork 资产按 canonical source group 去重后计数，不直接相加。明确 synthetic CI overlay 和未独立人类确认的规范边界。
建立 GLOBAL_GROUP_LEDGER，使用已存在 source ID、split_group、alias、原始场景/理论身份、规范/任务合同、可见观测哈希及历史训练/评估曝光清单；同一根派生的不同历史、授权、角色、菜单、动作、机制变体始终同组。出现来源别名或近义重构跨组时合并或隔离。最终封存数据不读取内容做选模。区分 (i) 已训练/开发过的历史数据；(ii) 当前读出未拟合但已被项目评分的迁移面板；(iii) 从未用于模型选择的独立来源开发/最终面板。不得将 (ii) 写成 (iii)。来源数量不足时缩小可声称范围，不伪造新测试。
冻结一张按 domain × knowledge mechanism × contract × label type 的覆盖矩阵；用已有原生评估确定哪些根满足当前历史翻转、未来可达性差、无关 hold、授权恢复和自主任务执行合同。没有对应证据的组合标 N/A，而非负标签。比如协商的概率未来事件与 ProofWriter 的确定性有限菜单不同，PiSAs 保护成本对不自动构成违规/合规对。
训练目标按实际资格：
- 原生完整可接受集：set CE；完整可核验 T,V 后果：候选/过程/读出监督。A 的有限可达性与 B 的已发生交付判断分别标注。
- 仅有 reference chosen/rejected：标准排序/偏好监督，仅对该对比较；不将 rejected 当违规或 chosen 当唯一正确；不假称 target Qpi。
- 安全任务完成等价的 cost pair：成本排序；成本不能奖励主动制造死路后退出。
- Task-only/原子授权/历史 hold：相应任务或规范监督，缺失 CI 标签 mask。
- 过程证据：由实际可见收件、公开规则和许可候选推出；未来分支明确标 hypothetical。合规/不可达证明的有限完备范围须可验证；不得把 evaluator-only hidden truth 输入学生。
每个域的有效监督池都进入同一共享模型的开发训练；训练/验证按源组分层，不因单域阴性而排除整个域。按域先均衡采样、域内源组均衡；同根多行仅增加监督覆盖不增加统计权重。完整清单、实际曝光、token、分域资格和排除原因作为 DATA_USAGE_LEDGER。不是要求所有3559行机械拼成同一种loss。

## 3. 三类评价任务，所有策略同用原生执行器
L（local knowledge sensitivity）：同一任务/规范/接收者/动作目录，只改变实际交付历史；在可完成历史需完成，在危险历史需合法替代（无合法成功才允许安全退出）。加保持任务与规范结果的无关历史变化，授权放开后的合法披露恢复；两种共同菜单/语义顺序对齐，不从不相关的两场景均分推断条件正确。
F（future reachability）：两个当前合法、当前任务进展和成本匹配的行动，实际改变后续安全完成可行性。在有严格差的根才计算首步排序、regret；若没有足够原生长程反转根，报告覆盖，不能将 local flip 冒充长期反转。有限参考 F_H 与真实策略 Q^pi 分开。协商等随机环境依据原生事件模型定义期望，使用共同随机种子/相同外生事件或可枚举原生期望；不能与确定性 case 的单次可达性混淆。
E（end-to-end）：从同一初始观察起，由同一共享检查点分别扮演各实际角色；执行真实选择的原生动作，更新交付账本与任务状态。只评价已实际发生的交付和推断，不把私有草稿当作外泄。完整菜单与原生状态由环境提供，模型输入不见 evaluator tags。报告真实任务、风险、合规成功、成本。
L/F 是科学机制诊断，E 是核心效果。拒绝式策略不能因为危险侧安全就得到联合正确。只对已证明任务可完成的初始根计机会成功，始终不可完成的根另报。所有策略共享测试根与外生事件。对支持自然消息/工具文本的域，增加真实可执行文本接口（不以模型外部修复输出救分），量化受控菜单与自由生成间差异。

## 4. 训练开发与正式确认严格区分
当前 16-root fit、128/32 ProofWriter 三臂、过程 S1/S2/S3、读出 B1/B2/B3 均为开发证据。它们用于估算预算、判断输出接口和可学习性，不能成为未见正式 test 的结果。保留原预登记与所有结果；不因后续拟合改变原 NO_GO。
开发候选不再无限增加：已有两条（P=过程监督内化策略；R=共享候选读出）+共同强 Action-SFT/ordinary preference learner。以相同多域合格数据合同开发；有条件的候选按支持子集训练/评价，绝不把较有利任务分布算作收益。保持共同初始共享4B、角色观察、原生菜单、数据分组；已发生的不同训练接口不能冒称同预算。原16-root读出及当前蒸馏继续按各自协议结束；多域工作不以ProofWriter过某个门槛为必要条件。
开发阶段固定资源包络，不设每项单独 GO 门槛。先用当前已执行日志估算每个训练方法 token/样本/更新成本，固定总 GPU-hour 与每个候选最大成本（沿用户当前授权，不开新付费资源）。以域平衡的有效根曝光为横轴，保存统一的学习曲线检查点（1/2/4/8 pass 或相应等预算 token 节点）；包括训练目标、训练根行为、开发根行为、任务/风险和成本。若资源不足，明确截断并不宣称收敛；避免只训练一个 epoch 就宣布算法失败。读出直接稳定求解和训练内分组正则选择，缓存冻结骨干表示；不重复数值求解诊断。
训练量与方法效应分别回答：样本匹配比较（相同根与监督，允许方法实际计算不同，报告差别）及训练/推理预算匹配或性能—成本曲线（不同每根 compute，不能同时假装相同曝光）。正式候选选择根据开发根宏平均历史联合正确及自主合规成功，保留风险/合法披露/授权与成本；如两个候选不支配，报告前沿，不强行合并。最终选定一个核心方法和一个必要机制消融。所有选择仅用开发/训练内部验证，冻结架构、学习目标、数据、训练次数、解码、阈值和正式对照后才解封最终面板。多次模型选择使用独立新来源确认，避免32个旧开发根反复选优。后续正式测试只报告，不以测试结果改方法。

## 5. 贯穿整篇论文的对照矩阵
C0：冻结同一共享模型+完整合法历史/规范/任务，统一直接行动接口；附真实静态规则或完整可见有限规划 oracle 上界（非学习方法，不能拿隐藏全知状态冒充公平基线）。
C1：充分训练的普通状态条件化 Action-SFT，原生完整可接受集/参考偏好监督，固定共同多域训练池，按实际标签支持使用CE或标准DPO。绝不是弱化为无历史输入。
C2：普通完整轨迹终局反馈/树传播方法（同动态原生评价器、同候选/续行采样、预算匹配）；若外部实现不兼容，明确是内部通用训练对照。
C3：PrivAct 官方核心偏好训练（LC-ARS+tree propagation）在相容接口的合理适配；CDI 保留独立 instructor 和执行反馈范式，作为系统级对照，执行器/模型成本单列，不强行改成共享actor然后叫原方法。先复用已有复现资产，优先最相关的1—2项，不把不兼容或未复现结果伪造成公平同算法比较。TG-CI 等系统级方法仅在可见任务图/规则相容时比较。原论文指标与本项目指标口径单列。
C4：最终选定 KCI 候选。所有内部方法看到相同历史/规范/候选和相同原生执行条件。仅 C4 优于无历史模型不够，必须对比 C1/C2。外部方法适配和能力差异透明报告。
机制对照依所选算法一次性指定：若过程监督为主，同样推理/行动输出接口、相近生成与训练预算、相同根与动作监督，普通任务推理/一般执行证据 vs 知识转移证据（后者额外证据价值及原生正确性明确）。禁止用完全无CoT弱基线单独归因过程机制。若读出为主，同一冻结骨干、候选、头结构、特征与数据支持，比较直接safe-success监督/普通历史评分与知识条件化分解，匹配标签曝光；当两轴与二元标签信息本来不同，明确检验监督结构而非只改loss。对无完整标签部分保持相同排序目标；不能把额外全表标签算成方法独有增益。若主张反事实配对本身提高学习，固定样本多重集和曝光，改变有效成组方式，而非将不相关或错标签作为弱对照；若主张长期价值，保持即时正确监督，改变真正续行信息，并用同状态终局反馈匹配控制。消融目标是解释最终方法，不要求每个历史组件独立创新。

## 6. 主指标、统计和论文实验表
固定主要效果：E 自主 STSR = 1[task success and no CI violation]，另独立报告 task success、episode CI violation（direct/incremental）、abort、UNKNOWN；L 真实相关历史严格联合正确（同根各必要条件均过），授权恢复和 hold 分开；F 在满足严格资格的根上首步精确可达性 regret 和实际续行表现。风险与效用不互相掩盖。成本条件于安全成功并报告对应分母，不奖励不完成。不同原生域的成功定义先固定，适用共同指标宏平均，域级结果和样本数完整显示；不可将pair准确率/参考oracle分数写作E。二元根的数目和置信区间须与独立单位匹配。
正式确认主表：4B共同面板，各方法域级和宏平均 E、L、风险/效用；长程F单独表，报告覆盖与有效样本。泛化表：未见根、预先保留的知识机制/合同（若支持足量数据），跨域共享学习与单域匹配模型对照（对共享方法固定训练预算、区分数据量收益）。消融表：最终方法及匹配机制对照；曲线图：训练曝光/compute与E/L、合法披露/违规；成本表：训练GPU时间/token、候选查询、rollout/生成token、推理延迟和显存。已归档的16根拟合和原NO_GO适合作为开发说明/附录，不作为主表泛化成绩。
正式核心方法/强内部基线至少3独立训练seed（7/1234/2025建议值，需冻结；相同共同SFT起点时明确仅代表后续优化随机性）；固定确定性头无需伪造三个相同seed，若抽样/骨干训练有随机性则按实际随机源报告。统计按源组配对（一个根的多个历史、候选、顺序、随机事件不能当独立样本），先报告每seed和域，再用根级分层配对区间；种子变异单列，若联合重采样须尊重交叉seed/root设计。无事件不等于安全保证；无显著差异不等于非劣。最终样本量先根据训练/开发中的配对差异和实际可用源组确定（目标为可分辨的实际效应，而非32根自动够用）；风险非劣只有提前确定容忍差、样本量和区间后才可主张。若不足，诚实报告估计与不确定性。不要设立没有科学依据的“多3根即创新”。
