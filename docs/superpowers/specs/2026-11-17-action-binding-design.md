# 关系知识进入语言模型行动决策：持续研究设计

目标保持为共享预训练语言模型自主行动。当前 main 为 b476787；此前结果只支持结构化参考模型，九个语言模型检查点仍未通过历史反转测试。

## 三项要求与完成证据

1. **首要：关系改变行动。** 在分组留出、新实体名称、关系反转、授权与任务依赖变化中，同时保留安全和可达效用。不能仅证明中间表示可被探针读出；要验证关系干预改变正确行动，恒等干预不改变行动，破坏必要关系会损害相应决策。最终须由模型自己的证据和自由生成动作完成任务，无真值屏蔽、规则接管或教师答案输入。三种子、逐分层和配对验收；小样本 95% 点门槛不冒称总体可靠性证明。
2. **真实多步协作。** 分开记录关系路径长度、环境状态转换、模型决策、消息发送、工具调用和有效依赖边。32 跳静态图不是 32 步协作。后续执行环境应有至少两个局部观测角色、状态改变与真实消息依赖；删除/延迟/重排关键消息应改变可执行后续或结果。禁止用 WAIT、重复文本或计数器填充成 32 步。
3. **业务规范有效且跨任务。** 外部可执行任务和规范来源分别核定。每条规范保留适用机构/场景、角色/对象/目的/授权/例外、证据位置及版本；缺失或冲突保持 UNKNOWN。至少两个任务家族的源级留出验证，独立核定标签及有意不适用的反例。公开 benchmark 作者定义的规则不自动等于真实组织政策，更不等于普遍自然规范。

三项均有直接证据才完成整个目标。P1 优先，P2/P3 保留为独立未完成项，不能被一个合成测试的通过替代。

## 路线选择（执行者判断）

- 继续扩大直接 SFT：改动最少，但此前三种配方忽略历史，盲目加训练无法区分关系计算与行动读出的问题。
- **先定位关系到动作的信息断点，再做分阶段/内部交换干预学习：采用。** 从冻结检查点开始，在相同输入上比较无证明、正确证明和交换后的矛盾证明。真值前缀仅用于诊断；随后选择由模型自己预测的关系瓶颈及匹配的直接监督对照。
- 推理时调用规则图判决器：可作系统参考与上界，但不能满足当前语言模型学习目标，不作为替代方案。

IIT/DIITO 提供干预内部表示的研究依据，不保证在本任务有效。证明文本干预与内部激活干预也不是同一种证据，应分别命名。

## 当前第一阶段

使用现有 pinned SmolLM2-135M、CPU FP32、现有三种配方 seed17 冻结检查点及未适配基座，先做有限诊断。既测旧训练组，也测新开发组；不以旧主测试调参。对 Planner 的唯一最优、历史反转成对状态测行动词元分布及 teacher-forced SAFE/TASK 位。诊断是强制答案前缀下的读出能力，不是自由生成成绩。

新开发组采用独立种子 210,000,000 起，深度 1/2/3、两个计算任务、成对相同词池/顺序。每深度 4 组；旧训练组也每深度 4 组。所有选择在运行前封存。各模式保留完整输入、词元长度、概率、原始最优词元、采样范围与 checkpoint SHA。

若正确关系证据显著改善行动，而原始关系仍被忽略，下一步集中修关系抽取/绑定并检验证据中介；若正确证据也不能改善，先修证据到行动的监督。不得直接用任一 oracle 诊断分数宣布原目标通过。
