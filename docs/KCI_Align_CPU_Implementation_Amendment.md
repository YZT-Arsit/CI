# KCI-Align v0.6 CPU 实现补记

日期：2026-11-12（America/Los_Angeles）。研究目标仍以 Proposal v0.6 为准；原 Proposal、Handoff、SPEC v0.5 保持原文。此补记记录为兑现原目标而修正的实现，不构成新研究问题、额外训练损失或真实方法效果声明。

## 1. 统计比较与评价合同

轨迹结果继续分为 CI 合规、任务成功、执行成本。确定违规意味着 safe_success=False，即使尚无任务终局；语义未知不能伪装成安全失败或安全成功。

旧 SPEC 的“比较 P(CI∧success)，两边样本全成功时比较成本”不能自动保证 CI 优先。当前 paired comparator 仅在完整配对样本的 CI 概率差通过预定 Hoeffding 界、且优选分支有完整安全成功见证时认证。安全成功率差及成本差作为分维诊断；成本单位不再错误地用 max_turns 归一化。未证明高优先级结果等价时不导出任务/成本硬偏好。这个保守实现会降低统计监督覆盖率，应报告其代价。

固定样本量、独立随机种子、冻结策略和正确审计是统计假设。单对 δ 不是全数据集 δ；规模化时必须预先分配整体错误预算，不能对每次追加采样反复使用原固定时点界。当前未实现通用 anytime-valid 推断。

`Q_safe*` 的标量形式仍是理论记号；没有成本范围与系数条件，不能声称任意 U−ηC 等价于词典序。当前实现使用证据分层，不新增该标量损失。

## 2. 环境、缓存和数据身份

- 初始本地知识和合法可读的实际交付日志进入知识闭包；草稿不进入。任务文字不预先透露匿名标识与姓名关联。
- 使用实例事实表、规范、成本及权限配置；配置哈希绑定环境、规范和任务 oracle 版本。已知成本和规范变化反映在模型观察中。
- 请求、决策、通知形成显式交付记录；决策正文反映实际声明，元数据不得编码隐藏 oracle 正确性。
- 候选仍来自合法 Observation，JSON 候选永不自称穷举。角色路由、非消息字段和实际正文分别核验。
- 同状态偏好还需相同可见 Prompt、参考/生成器版本、预算和期限。缓存绑定累计成本，输入/缓存输出快照隔离。
- 终局行动后的空 suffix 保留起始终局状态证据；空轨迹本身不是成功证明。
- DPR 仅接受确认违规或已确认的终局任务失败。未结束合法前缀与 UNKNOWN 不制造 repair 标签。
- 同 Prompt 出现反向严格偏好的批次被拒绝并保留冲突记录。这阻止矛盾数据进入训练，但不解决真实部分可观测性。

## 3. CPU pilot 的训练与数据边界

当前动态数据全部为原创建模示例，只有一个 identity–attribute join 规则家族、一个 eligibility-yes 基础任务。48 个换名配置仅为表面变体；所有变体归入同一基础组，没有独立 validation/test 世界。原始 PiSAs 或论文规范没有被自动变成新动态真值。

NumPy 实验是有限线性策略上的标准 DPO，以及可选的合成轨迹 SFT 初始化；不是 LLM 参数训练。其人工结构特征来自可见观察。拟合、顺序、标签噪声、权重与 beta 结果只说明小代理的管线行为。真实 Ollama 结果则是冻结模型从有限菜单选动作，不能替代自由文本语义验证或训练消融。

## 4. 复现入口

从 `code/` 运行 `python -B -m unittest discover -s tests -v`。

短实验由 `experiments/run_short_jobs.py` 驱动，每个子进程≤10秒；具体命令、输入、源代码哈希、输出和错误在 `artifacts/20261112_cpu_pilot/` 的 manifests、receipts、job_logs 里。重复运行应使用新的输出目录/manifest名，避免覆盖历史记录。完整结果及下一阶段门槛见该目录 `REPORT.md`。
