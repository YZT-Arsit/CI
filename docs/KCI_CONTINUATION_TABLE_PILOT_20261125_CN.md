## 2. Single mechanism: learn the joint continuation outcome
For a currently legal first action a and executable next action b, define T(s,a,b)=native task-supported indicator and V_N(s,a,b)=actual full two-step violation indicator. M_N=T*(1-V_N). In the verified deterministic two-step domain with complete downstream catalog and role-observable execution, F_N(s,a)=max_b M_N(s,a,b). The selector cannot use hidden state. This is a Boolean feasibility identity, not a reward proportional to the number of legal actions, and not a proof of model performance. It does not apply unchanged to longer/stochastic/partially observable domains.
The target is categorical C=(T,V). Train shared backbone using the existing action objective and a query-specific continuation loss. For query x=(authorized actor observation, first-action semantic content, next-action semantic content), use four class probabilities p_theta(c|x), and CE on C. The actual B decision query uses B's native observation following the actual first receipt, not A's private data. Use existing role interfaces. Do not insert K closure, witness proofs, oracle values, selected labels, or future private information into queries. The A catalog is explicitly authorized in ProofWriter. Authorized controls must use reconstructed native authorized observations; do not alter normative labels without changing actor-visible norms.
Primary deployment uses the same shared action scorer as baselines, no oracle, new runtime planner or guard. An optional diagnostic uses predicted p(T=1,V=0) and max over catalog to estimate F; this incurs extra inference and must not replace the matched primary comparison. For actual B, choose only through the existing actor interface. Four classes retain the distinction between task failure and CI-blocked task completion. Do not assume independent T and V probabilities or multiply marginals. Do not claim novelty of auxiliary CE/model-based learning alone.
