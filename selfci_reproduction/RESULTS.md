# SelfCI 公开权重复测与 KCI-Align 留出评测

在同一台 32 GB vGPU 上，Qwen3-4B-Instruct-2507 的 SelfCI 公开学生权重将 CI-RL Complete 从 **29.32% 提到 44.11%**，论文为 36.16% 到 55.34%。在 KCI-Align 统一多角色验证数据上，按记录计的动作参考命中从 **13.07% 降至 7.50%**。按 40 个来源组等权计算则为 **7.81% 到 8.96%**。两种加权回答不同问题。相对于同底座的 CI-RL 提升能够复现，KCI 结果缺少一致的正向迁移证据。

## 论文表 1 · CI-RL

下表运行固定提交中原样的 `run_test.py`。每个模型方法评价 73 个相同测试输入，每个输入按作者入口生成 5 轮。单位为百分比。I 表示不出现任何禁止关键词，U 表示包含全部要求关键词，C 要求两项同时满足。解析失败计零。

| Qwen3-4B-Instruct-2507 | 论文 I / U / C | 本次 I / U / C | 本次 C 命中数 | 解析成功数 |
|---|---|---|---:|---:|
| Initial | 58.08 / 65.75 / 36.16 | 49.04 / 60.82 / 29.32 | 107/365 | 357/365 |
| CI-RL | 69.04 / 63.01 / 45.21 | 63.56 / 65.48 / 40.55 | 148/365 | 358/365 |
| ContextDistill 对照候选 | 69.86 / 60.27 / 40.00 | 55.89 / 59.45 / 40.00 | 146/365 | 350/365 |
| SelfCI | 85.21 / 64.11 / 55.34 | 73.42 / 52.05 / 44.11 | 161/365 | 313/365 |

本次 SelfCI 相对 Initial 的变化为 I **+24.38**、U **−8.77**、C **+14.79** 个百分点。论文对应变化为 +27.13、−1.64 和 +19.18。对 73 道题成对重采样 10,000 次，C 差值的百分位 95% 区间为 **[+3.01, +26.85]**。这一区间描述本次解码条件下的逐题差异。原始测试集采用作者的 590/66/73 切分，测试集中 72 个唯一场景 seed 有 12 个也出现在训练集；此处沿用论文切分。

作者入口在 5 轮中重复指定采样种子 42。实际输出有重复，4B Initial 有 1 道题、SelfCI 有 10 道题五轮生成文本完全相同。公开学生快照与论文配置相符，论文没有给出表内结果的 checkpoint SHA。SFT 候选能追溯到作者的 distill 输出目录，缺少与论文 ContextDistill 训练语料的确切绑定。见[逐轮回答、计数与哈希](results/upstream/)和[逐题配对区间](results/paired_intervals.json)。

另用 vLLM 分别传入种子 42–46，4B Initial / CI-RL / SFT 候选 / SelfCI 的 C 为 14.79% / 16.99% / 28.77% / 42.47%。该入口的权重合并与作者脚本也有差异。Initial 五轮各有 71、4、1、2、73 个可解析回答，总计 151/365。这里的种子敏感性和解析失败会显著影响绝对值，尚未将与论文的偏差归因到单一因素。[不同种子原始统计](results/paired_ci.json)

## KCI-Align 最新统一多角色数据

版本为 `20261125_unified_roles_v1`。固定 40 个验证来源组，无训练组混入。4,133 个标签记录映射到 4,077 个唯一角色可见提示。按原生角色输入模板生成，使用贪心解码、4,096 token 上下文和最多 384 个输出 token，输入没有截断。评估 GPU 只接收角色可见的提示。评分在本地关联原始接受集合、拒绝项和合法菜单。一个角色的一步动作匹配参考的频率不能直接换算成团队任务成功率或隐私违规率。

| 4B 切面 | 记录 | Initial 命中 | SelfCI 命中 |
|---|---:|---:|---:|
| 全部 | 4,133 | 540 | 310 |
| PISAS | 2,961 | 482 | 197 |
| Deal or No Deal | 1,080 | 46 | 99 |
| MultiAgentPrivacy | 72 | 12 | 14 |
| ProofWriter | 13 | 0 | 0 |
| CI-Work | 5 | 0 | 0 |
| TOP-R | 2 | 0 | 0 |
| 单选项菜单 | 1,051 | 400 | 196 |
| 多选项菜单 | 3,075 | 140 | 114 |
| 开放输出约束 | 7 | 0 | 0 |

记录配对后，两者均命中 230 条，SelfCI 新增 80 条命中，同时失去 310 条原有命中。13 个来源组提高，6 个降低，21 个持平。按组等权差值为 **+1.15 个百分点**，按来源组配对重采样的 95% 区间为 **[−2.91, +4.65]**。PISAS 占全部记录的 71.64%，Deal or No Deal 占 40 个来源组中的 22 个，这解释了记录加权与来源组等权结果的方向差异。

在全部记录上，严格 JSON 无法解析的次数从 1,431 增至 1,665，生成菜单外动作从 1,948 降至 1,874，选择合法但未标注动作从 176 增至 242，命中已标注拒绝项从 32 增至 40。不同失败类别在原始记录中分别保留。上述比较没有对回答做格式修复。[评分摘要](results/kci_paired/summary.json) · [逐条配对回答与标签](results/kci_paired/paired.jsonl.gz) · [输入及标签哈希](kci_inputs/manifest.json)

在 4,077 个唯一提示上，底座有 1,404 条生成至 384-token 上限，SelfCI 有 1,639 条。映射到带标签记录后，达到上限分别解释 1,429/1,431 和 1,665/1,665 次 JSON 解析失败。4B 分词器下最长参考动作仅 121 个 token，95% 的记录最长参考动作不超过 48 个 token。因此上述严格命中率同时受到动作选择和生成长度的影响。

## 从头训练的单卡实测

4B 以同底座双反馈、双教师全词表反向 KL、0.5/0.5 权重、EMA 0.999 和有效 batch 2 实际完成 **8/8,850** 次优化器更新。16 条在线 rollout 共 15,181 个 token。学生与 EMA 从相同参数开始，更新后得到不同的参数哈希。训练使用 Transformers 生成以适配显存，未运行逐轮选模验证。8 步耗时 564.9 秒，平均 70.61 秒/步，峰值已分配显存 23.99 GiB，保留显存 30.69 GiB。以此速度线性估计完整 30 轮约 **174 小时**，另需逐轮验证；短程测速不足以评价训练效果。[实际训练日志](results/training_probe/probe.json) · [逐微步记录](results/training_probe/microsteps.jsonl)
